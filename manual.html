02 線に出す — Settings → OUTPUT

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

kanau は起動した瞬間から、パッチされているユニバースを 1 秒に 44 回、 止めずに送り続けます。送るボタンはありません。この章で決めるのは どの言葉で(Art-Net / sACN / CRMX)、どの線から、どこへ送るかだけです。

Settings タブ → OUTPUT の行を押すと開きます。

最短の道(Art-Net のノードが 1 台)

  1. iPhone をノードと同じ Wi-Fi(または有線アダプタ)に入れる
  2. OUTPUT を開く。Art-Net と AUTO が選ばれているのを確かめる(これが既定)
  3. Nodes answering が 1 以上になり、Sending が緑の数字になれば出ています
  4. Home へ戻り、状況行の左の丸が緑なら線は生きています

Nodes answering が 0 のままなら、この章の終わりの「ノードが答えないとき」へ。

面の中身(上から)

赤い帯 iOS is blocking this.

iOS が送信を止めているときだけ出ます。下の Switch to Unicast を押すと宛先が Unicast に変わります。 そのあとノードの IP を書きます(下の「Unicast」)。

理由は 2 つのどちらかです(2026-09 時点):

  • ローカルネットワークの許可を断った。 初めて送るときに iOS が「ローカルネットワーク上の デバイスの検索と接続」を聞きます。断ると 1 バイトも出ません。iPhone の設定 → kanau → ローカルネットワークを入れる
  • Multicast を iOS が拒んだ(sACN のとき)。sACN で Multicast を選んで iOS blocked multicast. と赤く出たら Unicast へ。 マルチキャストの許可は 2026-09-12 から TestFlight / App Store の版にだけ付いています。開発用の Debug の版では拒まれます

Art-Net ｜ sACN

網に出す言葉。どちらか 1 つです(排他)。切り替えると前の線を下ろしてから次を上げます。 Bluetooth(CRMX)はこれとは別に、並行して出ます(下の「CRMX」)。

Network — 線の一覧

見つかった線が全部並びます(wi-fi / ethernet / hotspot)。各行に自分の IP と、 その線の向こうで答えているノードの数(3 nodes / no reply)が出ます。

  • 既定は全部入り。All networks are in use. と出ています
  • 1 本だけ使いたいときは、その行を押す。全部入りから最初に押した 1 本が「それだけ」になります。 2 本目以降は押すたびに入 / 切
  • 全部切ると赤字で Nothing is going out over the network. Bluetooth still runs.
  • 住所を持たない線(no address)は押せません。アダプタを挿したのに Wi-Fi がここへ落ちたら、 iPhone が 2 本同時に持てていない、という答えです

iPhone は Wi-Fi を先に採ります(2026-08-08)。有線と Wi-Fi の両方にノードが居る現場では、 線ごとに別々のソケットで出すので、両方に届きます。

宛先 — AUTO ｜ Broadcast ｜ Unicast ｜ 255.255.255.255(Art-Net)/ Multicast ｜ Unicast(sACN)

Art-Net は札が 4 枚、2 段に並びます(2026-09-12 の姿)。

宛先どこへ送るかいつ使うか
AUTO答えたノードへ名指し(ユニキャスト)で送り、答えない機材のために 1 秒に 1 回はその線のブロードキャスト(例 192.168.1.255)も撒く。誰も答えなければブロードキャストだけ。札の下に 応答したノードへ送ります。応答しない機材にも、ブロードキャストが届きます。既定。まずこれ(2026-09-12 に名前が付いた。中身は 2026-08-16 から同じ)
Broadcast名指ししない。 全部の線のサブネットのブロードキャストへ毎フレーム繋がっているのに光がカクつくとき(下の「AUTO が効かないとき」)
255.255.255.255同じセグメントに居る全部。IP 設定が合っていなくても届く。ルーターは越えないノードの IP が 169.254.x.x(自動)のまま等で、AUTO のブロードキャストが届かないとき。iOS が拒むことがある(赤で出る)
Unicast下に書いたノードの IP へ直接。全ノードに全ユニバースが届き、各自が自分のぶんを取るiOS が止めたとき。ポーリングに答えないノード。ブロードキャストを嫌う網
Multicast(sACN)ユニバースごとに決まった 239.255.x.xsACN の既定。iOS が拒んだら Unicast へ

Unicast を選ぶと下にノードの一覧が出ます。IP を打って Add。読めない住所は足せません。 1 台も書いていないと赤字で No node IPs entered. — 何も出ていません。

AUTO が効かないとき — Broadcast に切り替える

AUTO はノードが答えた IP へ名指しで送ります。その IP はノードの自己申告で、嘘をつく機材があります (0.0.0.0 と名乗る機材で 2026-08-25 に 1 度踏んでいます)。そのとき kanau は届かない番地へ名指しで撒き、 その機材に届くのは 1 秒に 1 回の命綱だけ = 1 fps。画面は Nodes answering 1 と言うので、いちばん切り分けにくい壊れ方です。

Nodes answering が 1 以上なのに光が 1 秒に 1 コマのときだけ、Broadcast に切り替える。 名指しをやめ、全部の線に毎フレーム撒きます。 255.255.255.255 は逃げ道になりません(カーネルが選んだ 1 本の線にしか出ない)。 カクつきには他の原因もあります(時計の詰まり、線の混雑)。先に状態のカードを読む順は 14 章「光がカクつく・遅れる」。 他の原因で Broadcast にすると、名指しで届いていたものを遅いブロードキャストへ戻すので逆に遅くなります。

RESCAN(Art-Net のとき、宛先の札の下)

名簿を空にして、その場でノードに聞き直します。ふだんは待てば揃いますが、抜き挿しが多い現場向けです。

起きたこと押さなければ押すと
ノードを足した最大 3 秒で名簿に載るすぐ
ノードを抜いた10 秒は名簿に残る(その番地へ撒き続ける)すぐ落ちる
番地を変えた古いのが 10 秒残り、新しいのが 3 秒後に載る1 回で揃う

線は途切れません(名簿が空の間はブロードキャストへ落ち、返事は数ミリ秒で戻る)。 覚えていた相手も忘れるので、自分で外した機材を Node gone と赤で言うことはありません。 線が 1 本も開いていなければ薄くなって押せません。

Sending が緑でも、灯体が点くとは限りません。 「出ている」と「届いている」は別です。 Nodes answering が 0 のときは状況行の丸が赤 No node になります。

Net / Sub / Uni

Art-Net のユニバースは、ノードの側では Net / Sub-Net / Universe の 3 つの数で聞かれることがあります。 通し番号 = Net × 256 + Sub × 16 + Uni。ユニバース 16 以上で要ります。15 以下なら Net と Sub は 0、 Uni はその数そのままです。 出すのは Settings → SETTINGS → Art-Net → Net / Sub / Uni を入れたときだけ(既定は切)。

sACN の priority(0 / 100 / 200)

同じユニバースを 2 台が送ったとき、受け手は高い方を採ります。kanau の既定は 100。

Universes

パッチされているユニバースが全部並びます。台数 / いま光っている台数 / ON OFF。 OFF は 0 を送り続けます。送信を止めるのではありません。 線から消すと、ノードは最後に 受けたフレームを保ったまま点きっぱなしになるためです。切ってある間は状況行に 🔌 n が赤で出ます。

CRMX(Bluetooth)

Settings → OUTPUT の下に CRMX (Bluetooth) の節があります。CRMX の送信機(Aputure Sidus One など)へ、 Bluetooth で直接書き込みます。網の Art-Net / sACN とは別の道で、並行して出ます。

  • Bluetooth のスイッチを入れる。初回は iOS が Bluetooth の許可を聞きます
  • 見つかった送信機が並ぶので押して選ぶ。もう一度押すと外す
  • 選んだ送信機はユニバース 1 を運びます(U1 と出る)
  • 次の起動ではスイッチを入れるだけで同じ送信機に繋ぎ直します

同じユニバースが網と Bluetooth の両方から出ていると、赤で言います。 灯体が 2 つの卓に叩かれているのと同じで、ちらつきます。どちらかを切ってください(上の Network を 全部切るか、Bluetooth を切る)。自動では切りません。

スイッチを切ると送信機を手放します。それでも送信機が Art-Net を聞かないときは、送信機本体の Bluetooth を切るか、電源を入れ直す必要があります。Aputure Sidus Four は本体に Sidus BT の ON/OFF があり、取説 V1.0 §4.4 は Wi-Fi / Art-Net で使う前に切るよう書いています(2026-08-08 時点)。

線に別の卓が居るとき

同じユニバースを撒いている別の卓(kanau でも他の卓でも)が同じ網に居ると、 状況行の左の丸が赤になり、相手の IP が出ます。

表示意味出口
WAITING 192.168.1.20この iPhone が黙っています。 撒き始めた最初の 1 秒に相手の声を聞いたので、新入りとして引いた丸を押す → Send anyway? → Send で撒き始める。または SESSION で Join(子は線を持たない)
SHARED 192.168.1.20撒いている最中に相手の声を聞いた。撒き続けています。言うだけどちらかの人が止める

規則は 1 本です。他の卓が撒いている間、kanau は撒き始めない。撒いている最中に他の声が来たら赤で言う。止めるのは人。 単独で起動したときは何も変わらず、開いた瞬間に撒きます。同じ 1 秒に 2 台が起動して互いに黙ったら、 IP の小さい方が戻ります。

ノードが答えないとき(Nodes answering が 0)

上から順に。この一覧は 2026-09-12 時点の話です。 機種名の付いていない項目は kanau の側、 付いている項目は取説から写したものです。

  1. Network の行に no reply。 その線の向こうに誰も居ない。iPhone がノードと同じ網に居るか
  2. Sending が nothing。 出ていない。赤い帯が出ていれば、その指示どおり(許可 / Unicast)
  3. AUTO で届かないなら Unicast。 ノードの IP を書く。これで点けば、原因はブロードキャストの経路
  4. ノード側で Art-Net が切ってある。 LumenRadio CRMX Stardust は出荷時 Art-Net も sACN も Disabled(取説 2026-04-09 版 p.27「Factory default state」)。ノードの Web UI で有効にする
  5. Art-Net は両側の IP 設定が噛み合っていないと届かない。 Stardust の取説 p.21 「ArtNet uses unicast and broadcast, this means that IP settings of the unit needs to be properly set up」
  6. ノードの Wi-Fi が 5GHz だけ。 LumenRadio CRMX Stardust(取説 p.30)も Aputure Sidus Four (取説 V1.0 p.71)も Wi-Fi は 5GHz のみ。iPhone が 2.4GHz 側に居ると同じ網に居ない
  7. ノードの画面の出力の字。 Stardust は出力が小文字(a〜h)なら「設定はあるがデータが来ていない」、 大文字(A〜H)なら「データが来ている」(取説 p.18)。kanau から出ているかどうかが、ノード側だけで読める
  8. ポーリングに答えない機材は実在します。 Nodes answering 0 でも灯体が点いていることはあります。 この行は灯体が点いているかどうかは言いません

03 灯体を打つ — Patch

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

Patch タブは住所を決める場所です。灯体を足す、番号を振る、ユニバースと開始アドレスを決める、 グループを作る。色や光量はここでは触りません(Home の仕事)。

開くと上から: Re-patch / Fixtures / Select many の帯、＋ new patch、Patched n(機種ごとの一覧)、 ＋ new group とグループの一覧、Custom fixtures(自作。1 件も無ければ出ない)。

番号は 2 つある

Home の番号の鍵にどちらを出すかは Settings → SETTINGS → Fixture numbers → Show the fixture number。 既定は Unit no. です。同じ Fixture number を 2 台に打つと警告が付きますが、止めません。

  • 同梱の灯体データは 45 メーカー / 578 機種 / 11,347 モード(2026-09-12 の木で数えた)。 メーカーの公式の DMX チャートから起こしたものです

  • n channels share an address with another. The first one is kept.

04 触る — Home

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

Home はフェーダーの段です。ここに書くのは指で何が起きるかだけ。 色は 05 章、灯体ごとの設定は 06 章、エフェクトは 09 章。

フェーダー

触った場所は結果に影響しない

フェーダーは相対です。列のどこを触っても(数字の上でも、丸の上でも、フェーダーの下の余白でも)、 いまの値から、指が動いたぶんだけ動きます。ノブに飛びつきません。 舞台を見ながら手元を見ずに触るための作りです。指を置く位置を狙う必要はありません。

  • 触れた瞬間、ノブが少し大きくなって光ります(掴んだ印)。隣の列は 1pt も動きません
  • 縦に 3pt 動くまでは値が変わりません。押しただけでは動かない
  • 指で引いている間、画面の上に値が大きく出ます(番号 名前 62.4)。指の反対側へ寄るので、指に隠れません
  • 上限 / 下限(06 章)を付けてあると、そこで止まります。制限の外は橙の斜線、橙の印

FINE — 細かく

右下の FINE。

押し方何が起きるか
短押し段が進む: 無印 → FINE(1/10) → FINE+(1/100) → 無印
長押し押している間だけ次の段。離すと必ず無印に戻る

引いている最中に切り替えても、ノブは飛びません(毎回「直前からの移動量」しか使わないため)。 FINE+ は 1pt の指の動きが DMX の 2 段くらいで、機械の下限です。 FINE は卓ぜんぶに効きます(生のチャンネルや Pan / Tilt の行でも同じ意味)。

まとめて引く

丸を 2 つ以上タップして選んでおき、そのうち 1 本を引くと、選んだ全員が同じだけ動きます。 互いの差(隊形)は保ったまま。1 本が 100 で止まっても指を上へ動かし続ければ、残りも 100 まで届きます。 上下を繰り返しても隊形は崩れません。ロックした列は隊形から外れます。

番号の鍵 — ピアノ

フェーダーの下の番号は鍵盤です。右下の ＋ − で構えを切り替えます。

構え＋ − の見え方鍵を押すと
LOCK(既定)どちらも光っていない何も起きない。番号を読むだけ
＋＋ が赤く光る押している間だけ上限(既定 100)。離すと元の値
−− が赤く光る押している間だけ下限(既定 0)。離すと元の値
  • 押すたびに LOCK → ＋ → − → LOCK と回ります
  • 同時に何本でも押せます(和音)。それぞれ押す前の値を覚えて、離すと戻ります
  • 指を離さず横に滑らせると、通った鍵が順に鳴ります(グリッサンド)
  • 構えている間の赤は「触れば飛ぶ」の警告です。本番中は LOCK に戻しておく
  • 鍵の色: ＋ = 琥珀、− = 青。手で打った Fixture number は琥珀の字。Label color を付けた灯体は箱ごとその色
  • ロックしてある灯体(06 章)の鍵は緑の枠と 🔒 で、押しても鳴りません。滑らせても通過しません

起動時は必ず LOCK です。

⏻ — 電源

鍵盤の下の四角。値を保ったまま、出力だけを切る / 戻す電源ボタンです。

  • 押すたびに切り替わる。切ってある間は紫(四角と丸の輪)。数字は最後に合わせた値のまま残り、 ノブの絵だけ 0 へ落ちます(掴んでいる間は本当の値を描く)
  • 既定は全部 ON。起動したときに黙って消えている灯体は作りません
  • 切ってあっても、フェーダーは動かせます。光は出ません
  • 四角に長押しはありません。押している間だけ強制的に ON / OFF にする FLASH ON / FLASH OFF に変えるには、灯体の面(06 章)の Switch function。FLASH は何秒押し続けても切れません
  • ロックしてある灯体の四角は押しても効きません(🔒 が出ます)

GM — 全体マスターと B.O.

状況行の GM 100 を押すと、全体マスターの器が段の上に重なります。

中身何か
赤いフェーダー全体マスター。全部の灯体に掛かる。触り方はほかのフェーダーと同じ(相対、FINE も効く)
B.O.ブラックアウト。押すと全消灯、もう一度押すと戻る
→100100 未満のときだけ出る。押すと 100 へ

GM の札を長押しすると別の面が開き、100 / 75 / 50 / 25 / 12.5 / 0 の札で一発で入れます。 0 は B.O. そのものです(値を 0 にするのではなく暗転を掛ける)。バッテリー駆動の灯体を 「本番まで 2 時間あるから半分に」するための面です。

  • GM が 100 未満の間、札が赤く脈打ち、画面の縁が赤く点滅します。0 なら太く速く
  • 暗転中は GM の札が B.O. になり、押すと暗転が解けます。GM の値は失われません
  • 暗転中は器の中のフェーダーが 0 を指します(暗転を解くと元の高さへ)
  • 札や B.O. で値が変わるとき、フェードを掛けられます: Settings → SETTINGS → Master fade(既定は SNAP)。 指で引いたときは常に即座
  • ロックしてある灯体(06 章)は、GM を下げても B.O. を押しても落ちません。暗転中に光っている本数は 状況行の緑の 🔒 n に出ます

台に何を並べるか

  • 押した札が、台に出るもの。 それだけです。1 本のフェーダーは常に 1 灯体で、グループを 1 本にまとめる仕掛けではありません
  • 札を長押しすると、その札の全台の色と光量をまとめて調整する面(05 章)
  • All を選んでいるとき、いまのページに乗っている機種の札の縁が琥珀に寄ります
  • 選んでいる札は常に見える位置へ流れます

入口は 3 つ

帯の並び(上から)

灯体が持っている枠だけが出ます。1ch のディマーなら Intensity しか出ません。

Intensity

光量。0〜100。帯を引く / −10 −5 +5 +10(10 の倍数・5 の倍数へ吸着。47 → +10 → 50)/ 12.5% 25% 35% 50% 75% の札 / 数字を打つ。12.5 は丸めません(16 bit の灯体はそのまま)。

Color temperature(CCT)

K の帯。2700 3000 3200 4300 5000 5600 6500 10000 の札。灯体の範囲の外は端で止まり、 MIN / MAX と名乗ります。★ で Save this temperature。取っておいた色温度は機種をまたいで共通 (ケルビンは機種によらない物差し)。★ の札の長押しで微調整・削除。 CCT が二択の機種(128–255 = 5600K のような)は帯ではなく札が 2 つ出ます。

Green / Magenta

±の帯。Back to neutral で 0 へ。刻みは長押しで自分で決められます(Hold to edit the steps。数字を入れて Add)。

Crossfade

色温度側と色側の渡し。0 = CCT、100 = 色、のように灯体が決めた向きで動きます。 2 段以上ある灯体(Aputure NOVA II の White Light to RGB → CCTRGB to xy → Static Color to FX など)は、 2 段目以降の渡しが渡す先の帯の真上に出ます。

RGB / 素子

R G B の帯(0〜255。% で読むなら Channels の DMX 切替。06 章)。 灯体が持っている素子はそのまま帯になります: W A(Amber)Lime Cyan、本物の Hue Saturation、 CIE x CIE y。卓が作った言い換えではなく、灯体の枠なので常に出ています。

Gels(ジェル)

道出る灯体何か
Gel presets → LEE 3200 / LEE 5600 / Rosco 3200 / Rosco 5600RGB を持つ灯体Astera 公式の「DMX Values for common Colors」の実値(2026-08-27 取得)。3200K と 5600K で別の表。明るさは入っていない(フェーダーの仕事)

Gels → x/yx, y を持つ灯体LEE / Rosco の色度を x, y へ

一覧は選んでも閉じません。当てて、隣も当てて、✕ で閉じる。 ジェルを出すかどうかは Settings → SETTINGS → Gels → Gel presets(切ると全部の面で隠れる)。

★ Saved colors

Save this color で取っておく。機種ごとです(同じ DMX の値でも機種が違えば別の色)。 札を押すと当たる。長押しで名前・中身を直す / 削除。混ざった機種を選んでいても ★ は出ます。 CCT と G/M は ★ に入りません(色温度は上の ★ が別に持つ)。

ADVANCED COLOR(畳んである)

灯体の枠ではなく、卓が計算で作った言い換えをここに畳んであります。

  • Color picker: 横 = 色相 0〜360°、縦 = 彩度。明るさは載せません(それは光量フェーダー)。 丸の周りだけが指を取ります(丸から離れた所を払えば面がスクロールする)。色相は輪ではなく壁
  • R G B(上と同じ帯。RGB か CMY で受ける灯体だけ)
  • Hue / Saturation(RGB からの写像。灯体が本物の Hue / Sat を持つときは出ません)
  • C M Y(おまけ。255 − RGB)

卓の RGB が線まで届くのは、RGB か CMY で受ける灯体だけです。Hue / Saturation や x, y で受ける灯体では 上の素子の帯が本物で、ADVANCED COLOR の RGB は出ません。

複数台を選んでいるとき

触った瞬間に、選んだ全員が画面の値へ着地します(帯でも、±でも、札でも、数字打ちでも、★ でも同じ)。 差を付けたまま動かしたいときは、1 台ずつ開いてください(丸の長押し)。 1 台のときは相対も絶対も同じ意味なので、何も変わりません。

機種が混ざっているとき

出るのは Intensity / CCT / G/M / Crossfade / ★ だけ。RGB・Hue・Sat・素子は隠れ、 Open one model on its own to set color. と 1 行出ます(同じ DMX の値でも機種が違えば違う色が出るため)。 3200K は誰にとっても 3200K なので CCT は出ます。各灯体は自分の範囲で止まります。

セル(ピクセル)

PIXELS で開いたセルの丸を長押しすると、そのセルだけの色と光量。 まとめ(本体)の色を変えると全セルが従います。個別に触ったセルは、そのセルの色を持ちます。 本体の Intensity は全セルにまとめて掛かります。

色の組

同じ役が何組もあるモード(SkyPanel の Gel 1 / Gel 2、Titan の Color 1〜4)は、 組 1 が上の帯、組 2 以降が面の下の節に出ます。見出しはその枠のデータの名前(Gel 2, CCT Selection)。 場面(08 章)は組 2 以降を覚えません(2026-09-12 時点)。

作った色はどこに出るか

Home の丸、フェーダーの塗り、値の大表示、Patch の一覧の丸。全部この面で作った色です。

  • Astera の表の値は GelLibraryTests が公式 PDF と全数照合している(1183 件)。表そのものは開いていない

06 灯体の設定 — 灯体の面(下の段)

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

丸の長押し(または COLOR / 札の長押し)で開く面の、色の帯より下の段です。 1 台だけのときに出るもの(色の組・Channels・Mode・Channel roles・Patch)と、 複数でもまとめて触れるもの(上下限・Lock・Switch function・Battery save)があります。 複数で値が違うときは — や n of m と正直に出ます。触れば全台がその値に揃います。

上の段(名前と ‹ ›)

  • 左上の名前はその場で打ち替えられます。空なら No name
  • 1 台のとき ‹ › で同じ並びの隣の灯体へ移れます(面を閉じずに 1 台ずつ直す)
  • 右上 ZEN: この 1 台だけの画面(10 章)。光量が届く灯体のときだけ出ます

Lower limit / Upper limit

左が下限、右が上限(フェーダーの左右と同じ)。±1 ±5 と解除。 上限を 60 にすると、フェーダーは 60 で止まり、その上は橙の斜線になります。 ピクセル灯体では、セルの上下限は本体の上下限を破れません(本体 50、セル 80 なら 50)。

Lock

トグル 1 つ。掛けるとその灯体はどこからも動きません: フェーダー、鍵盤、⏻、色、生のチャンネル、 GM、B.O.、BATTERY SAVE、場面。守備範囲を選ぶ設定は 2026-08-27 に外され、 常に全部から守ります。トグルの下に Lock holds against everything, including B.O. と出ます(10 章)。

  • Home では丸の緑の外輪と 🔒、フェーダーの縁の緑、鍵と ⏻ の緑の枠で分かります
  • 複数選択で混在なら n of m locked。1 つでもロックされていれば押すと全解除、1 つも無ければ全ロック (外せない側が危ないので、全開放がどこからでも 1 押しで届く)
  • 掛ける瞬間、鍵盤や FLASH で一時的に飛ばしている値は、押す前へ戻してから固めます
  • ロック中は上下限を動かしても現在値をクランプしません。外した瞬間にクランプし直します

Switch function

鍵盤の下の四角(⏻)に何を割り当てるか。None / ON/OFF / FLASH ON / FLASH OFF。既定は ON/OFF(04 章)。

Battery save

この灯体を BATTERY SAVE の相手にするか(電池で動く灯体の印)。 印の付いた灯体だけが、状況行の BATTERY SAVE を押したときに落ちます(10 章)。 複数選択では n of m marked。まとめて付けるなら Patch の Select many → Battery。

Invert(軸を持つ灯体だけ)

Pan / Tilt の引く向きを反転します。報告する角度は変わりません。片方しか無い灯体は在る軸だけ出ます。

Label / Label color

  • Label: 表示名。同じ機種の全台で共有。長いと切れるので短くしてよい
  • Label color: 番号の背景の色(付箋)。No label color で外す

灯体データの枠の正体が間違っているときに直す道。役(Intensity / CCT / G/M / Crossfade / R / G / B / W / Strobe)と 綴りを、各枠について選び直せます。番地は動かないので確認は挟みません。 「フェーダーを上げても動かない」「色が別の枠へ行く」ときはここ。この灯体の打ってあるぶんに効きます。 次に同じ定義から打つときにも直しておきたいなら、自作(GDTF)の側の SAVE & EDIT(03 章)。

07 向き — Pan / Tilt とビーム

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

首(Pan / Tilt)、ズーム、アイリス、フロスト、ゴボは、灯体の面の Channels の行で触ります(06 章)。 向きだけの専用の面(AIM / POSITION)は 2026-09-05 に外しました。 コードは残っていますが入口はありません。

2026-09 時点のムービング対応は、動かせる・数字で置ける、までです。 「舞台を見ながら手元を見ずに首を撫でる」面は、選択後の UI を熟成させる中で改めて考える、と決まっています。

首の行(Channels → POSITION の棚)

丸を長押し → 下へスクロール → POSITION の棚。Pan / Tilt の行があります(16 bit の灯体は粗と微が 1 行にまとまる)。

何どう
読み度(+128.4°)。可動域は行の右に 0–540° / −135–135° と出る。灯体データが角度を持たない枠だけ %
帯つまみの周りだけが指を取ります(それ以外は面のスクロール)。掴んだ所から動かしたぶんだけ動き、叩いても跳びません
−10° −1° −0.1° +0.1° +1° +10°刻みはその枠の単位と分解能から決まる(Zoom や Iris も同じ道で、単位が違うだけ)。端で止まる
数字の欄度で打てます。資料の範囲の外は打てません
Home灯体の既定の向きへ。押し続けないと戻りません(機械が全速で走るため。琥珀の進みが満ちたら発火、途中で離せば戻る)
FINE / FINE+帯の感度が 1/10・1/100 に(04 章)
  • 死に帯(可動域の外の DMX 値、noEffect の区間)には落ちません。刻みも帯もその枠の区間の中で止まります
  • 灯体の既定が死に帯の中にある機種(Aputure Electro Storm CS15 / XT26 の 8 bit)は、触っていない状態では刻みが効きません。 帯か数字で一度中に入れてから
  • ロック(06 章)が掛かっていると 1 バイトも書きません
  • 触った向きは場面(08 章)と HISTORY に載ります。場面のフェードでは首は補間せず、GO の瞬間に置きます

Invert

灯体の面の Invert(軸を持つ灯体だけ出ます)。引く向きを反転します。読みの角度は変わりません。 灯体が上下逆に吊ってあるときの仕込みです。

ビーム(BEAM / GOBO / FOCUS の棚)

Zoom / Iris / Frost / Focus は連続の帯、ゴボやプリズムは名前で選ぶ行(プルダウン)。 どれも Channels の行の作法そのままです(06 章)。ホイールの中身は灯体データが宣言している型で棚が決まります。

動きのエフェクト

首の動き(DRIFT / PASS / ORBIT / EIGHT / BOX / SPIRAL / SEARCH / BREATHE / HANDHELD / WIND / JUMP / BALLYHOO)と ビームの動き(ZOOM PULSE / ZOOM BREATHE / IRIS PULSE / FROST BREATHE / GOBO SHAKE)は、EFFECT の面の MOVE / BEAM の棚から(09 章)。 首の動きはいまの向きを中心に度の差分で揺れます。光量のエフェクトと重ねられます。

  • 首の帯の掴み方と Home の押し続けは、実機(軸を持つ灯体)で
  • ムービングの設計書(docs/superpowers/specs/2026-09-03-ムービングライト-design.md)の段のうち、 どこまで出荷されているかは、この章を書いた日の木の Channels の行の姿で書いた

  • 上下限・ロック・電源(⏻)・Switch function — 卓の仕込み。場面を呼ぶたびにロックが外れては困る
  • 色の組 2 以降(05 章)と BATTERY SAVE の状態

  • フェード中はフェーダーそのものが動きます(線だけを補間しない)。途中で触れば、そこから相対で動く
  • 向き・ゴボ・生の値のように途中の値に意味が無いものは補間せず、GO の瞬間に置きます
  • 呼び出しは指を離した瞬間。押しただけでは変わりません

自動保存(SAVE ボタンは無い)

場面を呼んだあとに触ると、その場面が書き換わります。 手動の保存はありません。

  • 呼んだ場面の行に、触った後だけ点が出ます(「あなたが手を入れた」の印)。書き込みは指を離した瞬間に 1 回
  • 書き込み先から外れる道は 3 つ: 別の場面を呼ぶ / その場面を消す / ショーを開き直す
  • これ以上書き込まれたくない場面はロックする(Settings → Lock this scene)。呼べます。変わりません。 もう一度押すと外れる。行に 🔒
  • 「直前の上書きを取り消す」「このキューから離れる」は 2026-08-31 に外しました

怖がらなくていい理由: この卓では場面を押した時点で舞台が変わるので、「確認のために覗く」操作がありません。 押したなら現場はその絵になっていて、そこで直したなら直す意思があった、という作りです。

場面とエフェクト

場面と HISTORY

場面を呼ぶのは HISTORY(10 章)に 1 手として載ります(場面の名前で)。 場面の中身の変更は HISTORY には出ません。

場面はショーの中

場面はショーのファイルの一部です(11 章)。ショーを書き出せば場面も付いていきます。

09 エフェクト — EFFECT の面と Effects タブ

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

kanau のエフェクトはフリッカーボックスの代わりです。点滅、炎、稲妻、回転灯、首の揺れ。 名前で選んで、つまみが 2〜3 個。波形を編集したりチェイスを組んだりする機能はありません。 灯体自身が持っているエフェクト(内蔵プログラム)は 06 章の Channels の行から。

掛ける — Home の EFFECT

  1. Home で丸をタップして相手を選ぶ(1 台でも、何台でも、セルでも)
  2. EFFECT を押す(選んでいなければ押せない)
  3. 棚の札を押す。押した瞬間に走ります(選んでから適用、ではない)

走っている間、EFFECT のボタンがその名前を名乗り、丸とフェーダーの塗りが揺れます。

面の中身(上から: 固定の再生機 → ADJUST → ARRANGE → Applies to → SAVED → 棚)

上に固定: 帯と丸、PAUSE / RELEASE

走っている形の帯(4 秒の窓)と、相手の丸。下を流してもここは動きません。何も走っていなければ帯は空で、 ボタンは灰色。

Applies to — 誰に掛けるか

1 selected のように相手の数。SELECT ▾ を押すと相手を選ぶ面(灯体・グループ。押しても閉じません。✓ で選ぶ)。 選んだ相手は Home の丸の選択そのものです。

SAVED — 取っておいた札

札が 1 枚でも在るか、取っておけるものが走っているときだけ出ます。見出しの右の SAVE で、作っている途中でも名前を付けて札に。 札を押すと当たる(もう一度押すと止まる)。長押しで名前を変える・消す。札は相手を持ちません(どの灯体にでも当てられる)。

3 本のレーン

  • 外す: その 1 台だけ選んで RELEASE
  • Effects タブの札の × / ＋(下)

10 守る — 事故を防ぐ道具

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

本番中に指がかすっても舞台が変わらないための道具をまとめて。

SCREEN LOCK — 画面ごと止める

状況行の右端 SCREEN LOCK を長押し 0.5 秒。タップは揺れるだけで掛かりません(間違えて掛けないため)。

  • 掛かると画面が薄い紫の膜と斜線で覆われます。値は透けて読めます。送出もフェードも止まりません
  • 解くのは、真ん中の紫の溝を右へなぞる。8 割まで来れば外れ、途中で離せば戻ります。 溝の外を触ると溝が脈打って居場所を教えます
  • 面(Patch / Scenes / Settings)を開いている間は掛けられません(そもそもボタンに届かない)
  • ぶら下げたまま舞台を見る時間のための機能です。紫はこの卓の「止めてある」の色(電源オフと同じ)

灯体の Lock — その灯体だけ固める

丸の長押し → Lock(06 章)。どこからも動きません: フェーダー、鍵盤、⏻、色、生のチャンネル、 GM、B.O.、BATTERY SAVE、場面、そして MIDI とセッションの子。守備範囲を選ぶ設定は 2026-08-27 に外され、常に全部です。

見え方どこ
緑の外輪 + 🔒丸
縁が緑で太いフェーダー
緑の枠 + 🔒鍵盤の番号と ⏻(押しても効かない)
緑の 🔒 n状況行。暗転中に、まだ光っている灯体の数(0 なら出ない)

画角に入っている実用光、決めたランプ、のためのものです。B.O. を押しても消えません。 暗転しているつもりで明かりが残るのが一番怖いので、状況行の緑の数が必ず言います。

BATTERY SAVE — 電池の灯体だけ落とす

電池で動く灯体に印を付けておき、本番までの待ち時間にまとめて絞る道具です。

  1. 印を付ける: Patch の ＋ new patch の Battery save、灯体の面の Battery save、Select many の Battery
  2. 状況行の BATTERY SAVE をタップ → 印の付いた灯体だけが Save to の値まで落ちる(既定 1.5 秒のフェード)。 入っている間は札が緑に光り、画面の縁に緑の枠(光が滑る)。もう一度タップで戻る
  3. BATTERY SAVE を長押しすると設定の面: SAVE −50% / RELEASE の大きなボタン、Save to の刻み −25% −50% −65% −75%(既定 −50%)、フェードの秒

印が 1 台も無いときは、ボタンの代わりに「どこで印を付けるか」の 1 行が出ます。 GM とは掛け算で共存します。ロックした灯体は落ちません。 刻みとフェードは Settings → SETTINGS の時間の並びからも触れます。

GM の赤い枠

GM が 100 未満のままだと、札が赤く脈打ち、画面の縁が赤く点滅します(0 なら太く速く)。 ドラマの現場では GM を落としたまま本番に行かないので、遠慮なく目立たせてあります。戻すのは GM の札 → →100。 暗転中は赤の枠は出ず、B.O. の札が言います(押すと解ける)。

HISTORY — 戻す・進む

Home の右上 HISTORY。タップでも長押しでも一覧が開きます。

  • 1 本の線と栞です。戻る = 栞を 1 つ前へ、進む = 1 つ後ろへ。一覧で好きな点を押せば、前へも後ろへも跳びます。 HERE がいま居る点
  • 戻った所から新しく触っても、後ろの点は捨てません。 線は「この卓が通った盤ぜんぶの記録」で、新しい点は常に末尾に足されます。どの行にも跳べます
  • 1 点は「その時点の盤ぜんぶ」: 光量・色・電源・上下限・生の値・エフェクト・暗転・全体マスター・パッチも入ります 。鍵(Lock)だけは入りません —— 鍵は取り消しから守る仕掛けなので、 戻してもロックした灯体は動きません
  • 途中の 1 手だけを抜くことはできません(各社の卓と同じ)
  • 直近 50 手。保存しません(アプリを閉じると消える)。ショーを開き直すと新しい線が始まります
  • 場面を呼ぶのは 1 手として載ります(場面の名前で)。そこから戻ると、呼ぶ前の状態に戻ります。 場面の中身の書き換えは載りません。一覧の底の文もそう言っています(2026-09-12 に実装側が直した)
  • 戻すときのフェードは一覧の Recall fade time(SNAP / 秒)
  • 戻る先が無いとき、HISTORY は灰色で、押しても揺れるだけ

ZEN — フェーダー 1 本だけ

灯体の面(06 章)の右上 ZEN(1 台で、光量が届く灯体のとき)。

  • 画面が真っ黒になり、真ん中の 1 本と数字だけ。名前も帯も鍵盤もありません
  • 触れるのは画面ぜんぶ。相対なので、どこに指を置いても値は飛びません。FINE は効きます
  • 数字は何桁でも中心。下に小さく番号と名前
  • 入った直後だけ「タップで戻る」の 1 行が 2.5 秒出て消えます。戻るのはタップ(引いた指では戻らない)
  • 右上の歯車 → その灯体の上限 / 下限
  • OLED では画素が本当に消えるので、客席を照らしません

隠したものには必ず居場所

この卓の約束です。切ったもの・絞ったものは、画面のどこかに必ず出ます。

11 ショー — 保存と持ち出し

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

ショー = 現場 1 つ。 パッチ、グループ、場面、いまの明かりが 1 つのファイルに入っています。 保存ボタンはありません。触るたびに保存されています。

いつ保存されるか

何いつ

いまの明かり(光量・色・電源・上下限・ロック・生の値・エフェクト)触り終わって 2 秒後。背面に回った瞬間(電話が来た、画面が消えた)にも

だから、落ちても・電池が切れても・再起動しても、さっきの明かりがそのまま戻ります。 線は 44 Hz で流れ続けるので、Wi-Fi が切れても灯体は最後の値を保ち、繋ぎ直しても卓の値は変わりません。

  • Home に灯体が 1 台も無いときは No fixtures patched yet. と Patch fixtures(見本のショーは 2026-09-12 に廃止)

12 MIDI — つまみとボタンを割り当てる

書いた日: 2026-09-12(iPhone、0.2 build 228 の木)

外付けの MIDI コントローラーのノブとボタンで、フェーダーと幾つかのボタンを動かせます。 2026-09-06 に作り直しが決まっています(画面のボタンを押して機材のボタンを押す REC 方式。)。 以下は書いた日の姿です。

想定している機材(SPEC 2026-08 時点): Behringer X-Touch Mini / Compact を Standard モード・絶対値で。 MC モードでは CC が来ません。

Settings → MIDI

節何か
MIDI controller のスイッチ既定は切。入れた瞬間に MIDI を開き、切ると閉じる(差していない人に起こさせない)
Inputs / Last CCいま繋がっている入力と、最後に届いた CC。まず「届いているか」をここで見る

Knobs枠ごとに Learn(構えて回す)
Buttons仕事ごとに Learn(構えて押す)

MIDI map file割り当ての Export / Import(.kanaumidi)。機材に付くものなので、ショーとは別のファイル

GLOBAL 10

枠は場所です。ノブ 1〜10 が「画面の先頭の 10 本」を動かし、ページや札を変えれば相手も変わります。 もう 1 つのノブが全体マスター。1 枠ずつ Learn → Turn… の間にノブを回す。 枠 10 は欠番(2026-08-25 に系統マスターが無くなった席)。

FIXED

灯体 1 台 = ノブ 1 つ。灯体ごとに Learn。ページや札を変えても相手は変わりません。 連番の自動配りはありません。全部手で付けます。

飛びつかない

物理のノブはモーター付きではないので、画面の値とノブの位置は必ずずれます。 ノブの値がいまの値を跨ぐまで、何も動きません(フェーダーの相対ピックアップと同じ考え)。 62 で使っている明かりが、ノブが 0 の所にあるというだけで落ちることはありません。 ページ・札・モードを変えたら握りは捨てられ、次のノブは跨ぎ直しです。

Send values back を入れると、X-Touch Mini の LED リングに今の値が返ります(20 Hz、変わった時だけ)。 跨ぐまで効かないノブが「壊れたノブ」に見えないための機能で、pickup と対で意味を持ちます。相手の居ない枠は 0 が返ります。

ノードが答えない(Nodes answering 0)

02 章の「ノードが答えないとき」。要点:

  1. Network の行が no reply → iPhone がノードと同じ網に居ない。LumenRadio CRMX Stardust と Aputure Sidus Four の Wi-Fi は 5GHz のみ(取説 2026-04-09 版 p.30 / V1.0 p.71)。2.4GHz 側に居ないか
  2. AUTO で届かないなら Unicast にしてノードの IP を書く。ノードを抜き挿ししたなら RESCAN
  3. Stardust は出荷時 Art-Net も sACN も Disabled(取説 p.27)。ノードの Web UI で有効に
  4. Art-Net は両側の IP が噛み合っていないと届かない(Stardust 取説 p.21)
  5. Stardust の画面: 出力の字が小文字なら設定はあるがデータが来ていない、大文字なら来ている(取説 p.18)
  6. ポーリングに答えない機材は実在する。Nodes answering 0 でも点いていることはある

繋がっているのに 1 バイトも出ない

Sending が nothing。sACN で Multicast を選んでいると、iOS が拒むことがあります(マルチキャストの許可は TestFlight / App Store の版だけ。開発用の版では必ず拒まれる。2026-09-12 時点)。 Unicast にしてノードの IP を書く。Art-Net の AUTO はこの制限を受けません。

ちらつく

  • 同じユニバースが網と Bluetooth の両方から出ている。Settings → OUTPUT の CRMX の節に赤で出ます。どちらかを切る。 Aputure Sidus One / Four は Art-Net でも CRMX でも受けるので、両方から来ると 2 つの卓に叩かれた状態になります
  • 別の卓が同じユニバースを撒いている(SHARED / WAITING)
  • 灯体側の平滑化と、別のアプリ(Aputure Sidus)からの指示が混ざっている(2026-08-25、現場の仮説)。入口を 1 本にして切り分ける

光がカクつく・遅れる

原因は 1 つではありません。先に Settings → OUTPUT の状態のカードを読む(切り分けのために在る段です)。上から順に。

見えるもの正体何をするか
1. Sending が nothing出ていない宛先か許可の問題。「光らない」の表へ
2. Clock が 100 ms 超で赤iPhone の中が詰まっているBroadcast にしても直らない。開いている面を閉じる、アプリを入れ直す
3. Nodes answering が 1 以上なのに、光が 1 秒に 1 コマノードが自分の IP を間違って名乗り、AUTO が届かない番地へ名指ししている(Destination に見慣れない番地 + ↦)宛先を Broadcast に。RESCAN では直らない
4. Clock は健康で、ノードの往復(ms)が 100 超線か機材の側(AP の省電力、Wi-Fi の混雑)線を変える、有線にする
5. 全部健康なのに遅い灯体側の平滑化。別のアプリ(Aputure Sidus)からの指示と混ざっている(2026-08-25、現場の仮説)入口を 1 本にして切り分ける

Broadcast の出番は 3 だけです。他の原因でも切り替えると、名指しで届いていたものをわざわざ遅いブロードキャストへ戻すので、逆に遅くなることがあります。
