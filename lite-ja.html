Kanau Lite

Kanau Lite 1.3 (31) の時点

Kanau Lite は、iPhone や iPad を 1 台の灯体にする無料のアプリです。卓から Art-Net か sACN で送った DMX を受け取り、画面の色と明るさ、背面のライト、振動を動かします。アカウントの登録も広告もありません。

卓がなくても、CONTROL で明るさと色を決めて、手元で灯せます。FX & MEDIA と ULTIMATE のモードでは、動く絵柄や、自分で入れた画像と動画も画面に出せます。

用意するもの

  • iOS 17 以降の iPhone か iPad。
  • 卓から操作するときは、Art-Net か sACN を送れる卓。Kanau でも、ほかの卓でもかまいません。
  • 卓と同じネットワーク(Wi-Fi か有線)。最初に開いたときに「ローカルネットワーク」へのアクセスの許可を求められるので、許可してください。

始め方

  1. Kanau Lite を開きます。アイコンの絵と名前が一瞬出ます。タップすると飛ばせます。
  2. 画面の下からパネルが開き、SETUP が出ます。Kanau Lite を開くたびに、この形で始まります。
  3. Mode を選び、Art-Net か sACN を選んで、Universe と Address を設定します。
  4. 下の START を押します。パネルが閉じます。
  5. 卓から、その Universe と Address へ DMX を送ります。届くと、画面が灯りになります。

START を押すまでは、DMX が届いても画面は光りません。卓を使わずに灯すときは、手順 3 の代わりにパネルの上の CONTROL を押して明るさと色を決め、START を押します(下の「CONTROL」)。

パネル

パネルは画面の下から開き、上の 3 割ほどは灯りのまま見えます。パネルには、上から次のものが並びます。

  • 左上の ×、CONTROL と SETUP の 2 つのボタン。
  • DMX の行(下の「DMX の ON と OFF」)。
  • CONTROL を開いているときは、LIGHT、MACRO、MEDIA のボタン。
  • 選んだ画面の中身と、いちばん下の START。START はどの画面でも同じ場所にあります。

パネルを閉じるには、START を押すか、左上の × を押すか、パネルの上端の線をつかんで下へ払います。どれで閉じても、START を押したときと同じです。

灯りの間にパネルを開くには、右上の薄いスイッチを右端までスライドし、現れた EDIT を押します。EDIT は 3 秒で消えます。灯りや宛先の画面をタップしても、パネルは開きません。

DMX の ON と OFF

パネルの 2 つのボタンのすぐ下に、DMX の行があります。左から、DMX の ON と OFF、宛先(例: U1 · 001)、信号の状態です。信号の状態は、受け取っている間は Receiving、届いていない間は No Signal と出ます。

ON の間は、卓が送っていれば卓の灯りが先です。卓が送っている間は CONTROL が薄くなって押せず、その下に理由と、DMX を OFF にすると手元で灯せることが出ます。卓が 5 秒止まると CONTROL を押せるようになり、押すと手元の灯りに替わります。手元の灯りの間に卓がまた送り始めると、卓の灯りに戻ります。

OFF にすると、卓の DMX を聞かず、いつも手元の灯りになります。SETUP の Art-Net / sACN、Universe、Address は薄くなり、変えられません。前の設定は残り、ON に戻すとそのまま使えます。ON と OFF の選びは保存されます。

宛先の画面

START の後、DMX が ON で、まだ何も届いていない間は、黒い画面に次の 3 行が大きく出ます。これを宛先の画面と呼びます。何台も並べても、離れた所から番号を読めます。

  • Universe と Address。琥珀色で出ます(例: U1 · 001)。
  • Mode(例: 2: SCREEN RGB 9ch)。
  • つながっているネットワーク、この端末の IP アドレス、受け取るプロトコル(例: Wi-Fi 192.168.1.24 · Art-Net)。ネットワークがないときは No network と出ます。

その下に、パネルの開き方が小さく出ます。宛先の画面はタップしても何も起きません。DMX が OFF の間は宛先の画面は出ず、手元の灯りになります。

CONTROL

CONTROL は、手元で灯すときの明るさと色を決める画面です。中に LIGHT、MACRO、MEDIA の 3 つがあります。決めた値は保存され、次に開いたときも同じです。スライダーは触った所へ跳ばず、指を動かした分だけ動きます。

LIGHT には次のものが並びます。

  • Intensity: 明るさです。
  • WHITE と COLOR: WHITE では、Color Temperature と、2700、3000、3200、4300、5600、6500 のボタン、Green / Magenta で白を決めます。Green / Magenta は左がマゼンタ、右がグリーンで、真ん中の近くでは 0 になります。COLOR では、Hue と Saturation で色を決めます。
  • Back Light: 背面のライトの明るさです。背面のライトがない端末には出ません。

絵柄を出している間は、WHITE の代わりに ORIGINAL が出ます。ORIGINAL は、その絵柄が持っている色です。絵柄か画像か動画を出している間は、LIGHT のいちばん上にその名前と STOP が出ます。STOP を押すと絵柄と画像を止め、LIGHT で決めた色だけになります。CANDLE、FIRE、CLOCK、BEACON、TRAFFIC LIGHT、CROSSWALK のときは、LIGHT に色の設定は出ません。本物の物を写す絵柄なので、いつも自分の色で出ます。

MACRO には次のものが並びます。

  • Pattern: 一覧から絵柄を選びます。SOLID と、動く 19 の絵柄です(下の「FX & MEDIA」の Content と同じ)。CANDLE や CLOCK のように物を写す絵柄が先に並びます。
  • Color Macro: 一覧から色を選びます。最初に、絵柄が持つ色の組 Original 1〜6 が名前で並びます。SOLID にはありません。FROM LIGHT は LIGHT で決めた色で、その後に 15 色が並びます。LIGHT で色を変えると、Color Macro の色は外れます。CANDLE、FIRE、CLOCK、BEACON ではこの欄の名前が Type、TRAFFIC LIGHT と CROSSWALK では Country になり、一覧には自分の種類だけが並びます。
  • Speed、Amount、Size: 絵柄の速さと姿です。それぞれ、いまの絵柄で変わるものの名前で出ます(たとえば CANDLE なら Flicker)。その絵柄で効かないものは薄くなり、SOLID の間は 3 つとも薄くなります。TRAFFIC LIGHT と CROSSWALK では Amount が Direction になり、A と B の 2 つのボタンで選びます。

MEDIA の Media で、棚に入れた画像か動画を選びます(下の「Media」)。一覧には Off と、何か入っている番号だけが出ます。Play、Pause、Restart で再生を操作し、Restart は押すたびに頭から流します。画像か動画を出している間は、LIGHT の色と MACRO が薄くなり、Intensity と Back Light だけが効きます。

灯りの間

画面は受け取ったとおりに光ります。Kanau Lite を開いている間は、画面が最大の明るさになり、自動ロックもしません。卓からの DMX が止まっても、灯りは最後の姿のまま残ります。

Art-Net で 2 台の卓が同じ Universe へ送ると、Kanau Lite は先に届いた卓だけを聞きます。その卓が 5 秒止まると、もう 1 台を聞きます。

Kanau Lite が DMX を受け取るのは、アプリを開いている間だけです。ホーム画面に戻ったり画面をロックしたりすると、受け取りを止め、背面のライトと振動を止めて、画面の明るさを元に戻します。もう一度開くと、最後の灯りに戻り、また受け取ります。

画面は黒の上に、まず Media で選んだ画像か動画、その上に Content で選んだ絵柄を重ねて作ります。Mix はその割合で、0 では画像か動画だけ、255 では絵柄だけが見えます。Media が 0 のときや、その番号に何も入っていないときは、絵柄だけが出ます。Reserved 1 と Reserved 2 は、何もしないチャンネルです。

Content の最初の SOLID は、画面を色で塗ります。初期値のままなら、FX & MEDIA は SCREEN RGB と同じ光になります。残りの 19 は動く絵柄で、Speed で動きの速さを、Amount と Size で絵柄の姿を変えます。Content の 100–255 は空きで、SOLID と同じです。

絵柄はそれぞれ自分の色を持つので、色を何も設定しなくても、そのまま見られる姿で流れます。Crossfade は、0 で絵柄自身の色、255 で Red、Green、Blue の色になります。CANDLE、FIRE、CLOCK、BEACON、TRAFFIC LIGHT、CROSSWALK は、Crossfade がどこにあっても自分の色で出ます。

Color Macro は 5 ずつ区切られています。5–34 の Original 1〜6 は、その絵柄が持つ色の組です。50 から 5 ずつ、次の 15 色が並びます: 3200 K、4300 K、5600 K、Red、Orange、Amber、Yellow、Green、Cyan、Sky Blue、Blue、Deep Blue、Lavender、Magenta、Pink。0–4、35–49、125–255 は Off と同じです。CANDLE、FIRE、CLOCK、BEACON、TRAFFIC LIGHT、CROSSWALK は色を取りません。15 色のどれかを送ると Original 1 で出ます。BEACON はいつも Aviation Red です。CONTROL では Original 1〜6 が名前で出ます。たとえば CANDLE は Single、Pair、Trio、Japanese、Tea Lights、Candelabra、TRAFFIC LIGHT と CROSSWALK は Japan、USA、UK、Germany、France、China です。SETUP の Channels では番号で出ます。

TRAFFIC LIGHT と CROSSWALK では、Amount が向きを決めます。128–255 が A、0–127 が B です。A と B は同じ周期を半周ずらして回ります。交差点では、2 本の道に 1 台ずつ置きます。

画像と動画は、自分の色のまま出ます。Color Temp で暖かい方か冷たい方へずらせて、Screen Dimmer で暗くできます。動画は音を出さずに再生し、終わると頭からまた流れます。Playback は動画を再生するか一時停止します。Restart は、値が 171–255 に入った瞬間に 1 度だけ動画を頭に戻します。

COOKIE と ULTIMATE

SCREEN COOKIE は、画面を不規則なまだらの区画に分けます。区画ごとに 8 つのセルのどれかの色になるので、1 つのセルの色が画面のあちこちに出ます。いくつかの区画は、セルの色によらず黒のままなので、8 つのセルを全部光らせても光の間に影が残ります。影を増やしたいときは、卓でいくつかのセルを黒にします。

16: SCREEN COOKIE RGB 62ch は、先頭が Screen Dimmer で、Shape、Soft、Drift が続きます。その後に 8 つのセルが、CELLS のモードと同じく Dimmer、CCT、G/M、Crossfade、Red、Green、Blue の順で並び、末尾が Back Light、Vibration です。17: SCREEN COOKIE HUE SAT 54ch は、セルごとに Red、Green、Blue の代わりに Hue と Saturation を持ちます。

セルが出るのは、Content が SOLID で、Media が 0 のときだけです。このとき、Cells で画面の分け方を選びます。SCREEN では、画面全体がセル 1 の色になります。絵柄か画像か動画を出している間(Content が SOLID でないか、Media が 0 でないとき)は、FX & MEDIA と同じく画面は 1 つで、絵柄はセル 1 の色と Crossfade を使います。Media は値で見ます。0 でなければ、その番号に何も入っていなくても画面は 1 つです。Color Macro が効くのは、画面が 1 つのときだけです。画面を分けている間は効きません。Cells で 8 より少なく分けたときは、残りのセルのチャンネルは効きませんが、アドレスは使います。

Media

棚は、この端末に画像と動画を 1 から 51 の番号で置いておく場所です。SETUP の Media から開きます。どのモードでも開けるので、FX & MEDIA や ULTIMATE に切り替える前に入れておけます。

  • 空いている番号を押すと、写真アプリかファイルから画像か動画を入れられます。
  • 入っている番号を押すと、入れ替える、ほかの番号へ移す、消す、から選べます。移す先が埋まっているときは、2 つが入れ替わります。

卓では、Media のチャンネルで番号を選びます。1–5 が 1、6–10 が 2 と続き、251–255 が 51 です。ファイルはこの端末に置かれ、どこにも送られません。

卓でパッチする

Kanau では、この端末を Kanau Lite として、同じモードでパッチします(説明書の 03 章)。Kanau 1.3 の Kanau Lite のチャンネルは、Kanau Lite 1.3 と同じです。Kanau Lite 1.1 に合わせて作った灯体は、そのまま使えます。1.2 で足した値は、1.1 では空きだった所です。

ほかの卓では、SETUP の Channels と同じ順にチャンネルを並べた灯体を作り、同じアドレスにパッチします。チャンネルはすべて 8 ビットです。

Kanau Lite 1.0 に合わせてパッチした灯体は、14、15、18、19 のモードのチャンネルの数と、Color Macro と Content の値が違います。Kanau でもほかの卓でも、パッチし直してください。

Art-Net では、ノードを探す問い合わせ(ArtPoll)に Kanau Lite · U1 · 001 のような名前で応答します。ノードの一覧を出せる卓では、Universe と Address 付きのこの名前で見つかります。
