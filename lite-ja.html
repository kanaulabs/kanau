Kanau Lite

Kanau Lite 1.0 (2) の時点

Kanau Lite は、iPhone や iPad を 1 台の灯体にする無料のアプリです。卓から Art-Net か sACN で送った DMX を受け取り、画面の色と明るさ、背面のライト、振動を動かします。Kanau の LITE MODE を、単独のアプリにしたものです。アカウントの登録も広告もありません。

用意するもの

  • iOS 17 以降の iPhone か iPad。
  • Art-Net か sACN を送れる卓。Kanau でも、ほかの卓でもかまいません。
  • 卓と同じネットワーク(Wi-Fi か有線)。最初に開いたときに「ローカルネットワーク」へのアクセスの許可を求められるので、許可してください。

始め方

  1. Kanau Lite を開きます。アイコンの絵と名前が一瞬出ます。タップすると飛ばせます。DMX が届いたときも、すぐに消えます。
  2. 黒い画面に、受け取る番号が大きく出ます。これを宛先の画面と呼びます。画面のどこかをタップすると、Settings が開きます。
  3. Protocol で Art-Net か sACN を選び、Mode、Universe、Address を設定します。
  4. Done を押して閉じます。
  5. 卓から、その Universe と Address へ DMX を送ります。届くと、画面が灯りになります。

宛先の画面

DMX が届いていない間は、黒い画面に次の 3 行が出ます。何台も並べても、離れた所から番号を読めます。

  • Universe と Address(例: U1 · 001)。
  • Mode(例: SCREEN RGB 10ch)。
  • つながっているネットワーク、この端末の IP アドレス、受け取るプロトコル(例: Wi-Fi 192.168.1.24 · Art-Net)。ネットワークがないときは No network と出ます。

灯りの間に DMX が 6 秒届かないと、宛先の画面に戻ります。このとき、背面のライトと振動も止まります。

Settings

項目内容
ProtocolArt-Net か sACN。
Modeモードの一覧(下の「モードとチャンネル」)。背面のライトがない端末には、BACK LIGHT ONLY は出ません。
UniverseArt-Net は 0〜32767、sACN は 1〜63999。
Address1 から、そのモードのチャンネルが 512 に収まるところまで。

Universe と Address は、数字を入力するか − と + で設定します。その下の行に、画面、背面のライト、振動がそれぞれ使うアドレスが出ます(例: Screen 001–008 · Back Light 009 · Vibration 010)。

その下の Channels には、いまのモードのチャンネルが、アドレス、名前、値の意味の順に並びます。この端末にない機能(背面のライトや振動)の行は薄く出て、頭に Not on this device が付きます。その行もアドレスを使うので、卓では同じ数のチャンネルで数えます。

Settings の一番下には、Kanau Lite のバージョンと kanaulabs.app へのリンクがあります。設定は保存され、次に開いたときもそのままです。

灯りの間

画面は受け取った色になります。Kanau Lite を開いている間は、画面が最大の明るさになり、自動ロックもしません。

灯りの間に Settings を開くには、右上の薄いスイッチを右端までスライドし、現れた × を押します。× は 3 秒で消えます。

Kanau Lite が DMX を受け取るのは、アプリを開いている間だけです。ホーム画面に戻ったり画面をロックしたりすると、受け取りを止め、背面のライトと振動を止めて、画面の明るさを元に戻します。もう一度開くと、また受け取ります。

モードとチャンネル

モードは 9 つで、初期値は SCREEN RGB 10ch です。

BACK LIGHT ONLY のほかは、先頭が Screen Dimmer、末尾が Function、Back Light、Vibration です。SCREEN RGB 10ch のチャンネルは次の順です。値の欄は、Settings の Channels に出る字のままです。

HUE SAT のモードは、Red、Green、Blue の代わりに Hue(0–360°)と Saturation を持ちます。CELLS のモードは、Screen Dimmer の後に、分けた部分ごとに Dimmer、CCT、G/M、Crossfade と色が続きます。部分の番号は左上から数えます。8 分割は、縦の画面では 2 列 4 段、横の画面では 4 列 2 段です。

Crossfade は白と色の割合で、0 で白、255 で色になります。白は CCT と G/M で決まります。Crossfade が 0 の間は、Red、Green、Blue を上げても画面は白のままです。Screen Dimmer は画面だけを暗くし、背面のライトには効きません。Function を 128 以上にすると Proximity になり、端末の近接センサーを使います。

卓でパッチする

Kanau では、この端末を Kanau Screen として、同じモードでパッチします(説明書の 03 章)。

ほかの卓では、Settings の Channels と同じ順にチャンネルを並べた灯体を作り、同じアドレスにパッチします。チャンネルはすべて 8 ビットです。

Art-Net では、ノードを探す問い合わせ(ArtPoll)に Kanau Screen · U1 · 001 のような名前で応答します。ノードの一覧を出せる卓では、Universe と Address 付きのこの名前で見つかります。

Kanau の LITE MODE との違い

Kanau の LITE MODE(説明書の 02 章)と、受け取り方とモードは同じです。違うのは次の 3 つです。

  • DMX が届く前は、LITE MODE では WAITING と出ます。Kanau Lite では宛先の画面が出ます。
  • DMX が止まったとき、LITE MODE は最後の色のままです。Kanau Lite は 6 秒で宛先の画面に戻ります。
  • 右上のスイッチから出る × は、LITE MODE では LITE MODE を終わります。Kanau Lite では Settings を開きます。
