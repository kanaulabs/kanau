Kanau Lite

Kanau Lite 1.0 (4) の時点

Kanau Lite は、iPhone や iPad を 1 台の灯体にする無料のアプリです。卓から Art-Net か sACN で送った DMX を受け取り、画面の色と明るさ、背面のライト、振動を動かします。FX & MEDIA のモードでは、動く絵柄や、自分で入れた画像と動画も画面に出せます。アカウントの登録も広告もありません。

用意するもの

  • iOS 17 以降の iPhone か iPad。
  • Art-Net か sACN を送れる卓。Kanau でも、ほかの卓でもかまいません。
  • 卓と同じネットワーク(Wi-Fi か有線)。最初に開いたときに「ローカルネットワーク」へのアクセスの許可を求められるので、許可してください。

始め方

  1. Kanau Lite を開きます。アイコンの絵と名前が一瞬出ます。タップすると飛ばせます。
  2. Settings が開きます。Kanau Lite を開くたびに、まず Settings が出ます。
  3. Art-Net か sACN を選び、Mode、Universe、Address を設定します。
  4. 下の START を押します。
  5. 卓から、その Universe と Address へ DMX を送ります。届くと、画面が灯りになります。

START を押すまでは、DMX が届いても画面は光りません。

宛先の画面

START の後、DMX が届いていない間は、黒い画面に次の 3 行が大きく出ます。これを宛先の画面と呼びます。何台も並べても、離れた所から番号を読めます。

  • Universe と Address。琥珀色で出ます(例: U1 · 001)。
  • Mode(例: SCREEN RGB 10ch)。
  • つながっているネットワーク、この端末の IP アドレス、受け取るプロトコル(例: Wi-Fi 192.168.1.24 · Art-Net)。ネットワークがないときは No network と出ます。

宛先の画面をタップすると、Settings が開きます。灯りの間に DMX が 6 秒届かないと、宛先の画面に戻ります。このとき、背面のライトと振動も止まります。

Universe と Address は、数字を入力するか − と + で設定します。その下の琥珀色の行に、画面、背面のライト、振動がそれぞれ使うアドレスが出ます(例: Screen 001–008 · Back Light 009 · Vibration 010)。

次が Channels です。Settings を開くたびに畳んだ形で始まり、チャンネルの数だけが出ます(例: 10ch)。見出しを押すと開き、いまのモードのチャンネルが、アドレス、名前、値の意味の順に並びます。Kanau とほかの卓での打ち方の 2 行は、畳んでいても出ます。この端末にない機能(背面のライトや振動)の行は薄く出て、頭に Not on this device が付きます。その行もアドレスを使うので、卓では同じ数のチャンネルで数えます。

Settings の一番下には、Kanau Lite のバージョン、Made by Kanau Labs、kanaulabs.app へのリンク、Privacy Policy、Contact Support、Art-Net の表記、著作権の表記があります。設定は保存され、次に開いたときもそのままです。

灯りの間

画面は受け取ったとおりに光ります。Kanau Lite を開いている間は、画面が最大の明るさになり、自動ロックもしません。

灯りの間に Settings を開くには、右上の薄いスイッチを右端までスライドし、現れた × を押します。× は 3 秒で消えます。こうして開いた Settings は、左上の × で閉じます。

Kanau Lite が DMX を受け取るのは、アプリを開いている間だけです。ホーム画面に戻ったり画面をロックしたりすると、受け取りを止め、背面のライトと振動を止めて、画面の明るさを元に戻します。もう一度開くと、また受け取ります。

HUE SAT のモードは、Red、Green、Blue の代わりに Hue(0–360°)と Saturation を持ちます。CELLS と STRIPS のモードは、Screen Dimmer の後に、分けた部分ごとに Dimmer、CCT、G/M、Crossfade と色が続きます。CELLS の番号は左上から数えます。8 分割は、縦の画面では 2 列 4 段、横の画面では 4 列 2 段です。STRIPS は同じ幅の帯で、縦の画面でも横の画面でも、左から右へ数えます。

Crossfade は白と色の割合で、0 で白、255 で色になります。白は CCT と G/M で決まります。Crossfade が 0 の間は、Red、Green、Blue を上げても画面は白のままです。Screen Dimmer は画面だけを暗くし、背面のライトには効きません。Function を 128 以上にすると Proximity になり、端末の近接センサーを使います。

画面は黒の上に、まず Media で選んだ画像か動画、その上に Content で選んだ絵柄を重ねて作ります。Mix はその割合で、0 では画像か動画だけ、255 では絵柄だけが見えます。Media が 0 のときや、その番号に何も入っていないときは、絵柄だけが出ます。

Content の最初の SOLID は、画面を色で塗ります。初期値のままなら、FX & MEDIA は SCREEN RGB と同じ光になります。残りの 7 つは動く絵柄です。Speed で動きの速さを、Amount と Size で絵柄の姿を変えます。絵柄の色は画面の色から取ります。Color Macro が 0 でないときは、その色を使います。16 から、16 ずつ次の色になります: 3200 K、4300 K、5600 K、Red、Orange、Amber、Yellow、Green、Cyan、Sky Blue、Blue、Deep Blue、Lavender、Magenta、Pink。

画像と動画は、自分の色のまま出ます。Color Temp で暖かい方か冷たい方へずらせて、Screen Dimmer で暗くできます。動画は音を出さずに再生し、終わると頭からまた流れます。Playback は動画を再生するか一時停止します。Restart は、値が 171–255 に入った瞬間に 1 度だけ動画を頭に戻します。

Media

棚は、この端末に画像と動画を 1 から 51 の番号で置いておく場所です。Settings の Media から開きます。どのモードでも開けるので、FX & MEDIA に切り替える前に入れておけます。

  • 空いている番号を押すと、写真アプリかファイルから画像か動画を入れられます。
  • 入っている番号を押すと、入れ替える、ほかの番号へ移す、消す、から選べます。移す先が埋まっているときは、2 つが入れ替わります。

卓では、Media のチャンネルで番号を選びます。1–5 が 1、6–10 が 2 と続き、251–255 が 51 です。ファイルはこの端末に置かれ、どこにも送られません。

卓でパッチする

Kanau では、この端末を Kanau Screen として、同じモードでパッチします(説明書の 03 章)。Kanau 0.2 (368) の Kanau Screen にあるのは、BACK LIGHT ONLY から SCREEN 8 CELLS HUE SAT までの最初の 9 つのモードです。STRIPS と FX & MEDIA のモードは、ほかの卓と同じように灯体を作ってパッチします。

ほかの卓では、Settings の Channels と同じ順にチャンネルを並べた灯体を作り、同じアドレスにパッチします。チャンネルはすべて 8 ビットです。

Art-Net では、ノードを探す問い合わせ(ArtPoll)に Kanau Screen · U1 · 001 のような名前で応答します。ノードの一覧を出せる卓では、Universe と Address 付きのこの名前で見つかります。

Kanau の LITE MODE との違い

Kanau の LITE MODE(説明書の 02 章)と、受け取り方は同じです。Kanau 0.2 (368) の時点で、違うのは次の 4 つです。

  • DMX が届く前は、LITE MODE では WAITING と出ます。Kanau Lite では宛先の画面が出ます。
  • DMX が止まったとき、LITE MODE は最後の色のままです。Kanau Lite は 6 秒で宛先の画面に戻ります。
  • 右上のスイッチから出る × は、LITE MODE では LITE MODE を終わります。Kanau Lite では Settings を開きます。
  • LITE MODE にあるのは最初の 9 つのモードです。Kanau Lite には、STRIPS と FX & MEDIA のモードと、Media の棚もあります。
