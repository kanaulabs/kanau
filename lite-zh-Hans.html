Kanau Lite

截至 Kanau Lite 1.2 (27)

Kanau Lite 是一款免费应用，把 iPhone 或 iPad 变成一盏灯。它接收控台通过 Art-Net 或 sACN 发来的 DMX，驱动屏幕、背面灯和振动的颜色与亮度。不需要创建账号，也没有广告。

没有控台时，可以在 CONTROL 中设置亮度和颜色，手动点亮。在 FX & MEDIA 和 ULTIMATE 模式下，屏幕还能显示流动的图案，以及你自己的图片和视频。

所需条件

  • 运行 iOS 17 或更高版本的 iPhone 或 iPad。
  • 若要用控台控制，需要一台发送 Art-Net 或 sACN 的控台。Kanau 或其他控台都可以。
  • 与控台在同一个网络上，Wi-Fi 或有线均可。第一次打开应用时，它会请求 Local Network 权限，请允许。

开始使用

  1. 打开 Kanau Lite。图标和名称会短暂显示。点一下可以跳过。
  2. 面板从屏幕底部升起，显示 SETUP。每次打开 Kanau Lite 都是这样开始。
  3. 先选 Mode，再选 Art-Net 或 sACN，然后设定 Universe 和 Address。
  4. 点底部的 START。面板会关闭。
  5. 在控台上向该 universe 和地址发送 DMX。数据一到，屏幕就变成灯。

在点 START 之前，即使有 DMX 到达，屏幕也不会亮。没有控台时，可以不做第 3 步，改为点面板顶部的 CONTROL，设置亮度和颜色，再点 START（见 CONTROL）。

面板

面板从屏幕底部升起，上方约三分之一仍显示灯光。面板从上到下有：

  • 左上角的 ×，以及两个按钮 CONTROL 和 SETUP。
  • DMX 一行（见 DMX 的开与关）。
  • 打开 CONTROL 时，有 LIGHT、MACRO 和 MEDIA 按钮。
  • 所选画面的内容，以及底部的 START。START 在每个画面中位置相同。

要关闭面板，可以点 START，点左上角的 ×，或者抓住面板上边缘的横线向下滑。这几种方式的效果都与 START 相同。

灯亮着时要打开面板，先把右上角淡淡的开关一直滑到右边，再点 EDIT。EDIT 会在 3 秒后消失。点灯光或地址画面不会打开面板。

DMX 的开与关

面板两个按钮的正下方是 DMX 一行。从左起依次是：DMX 的 ON 和 OFF、地址（例如 U1 · 001）和信号。DMX 到达时信号显示 Receiving，没有到达时显示 No Signal。

DMX 为 ON 时，只要控台在发送，就优先显示控台的灯光。发送期间，CONTROL 变灰，无法点击，下方一行会说明原因，并说明把 DMX 设为 OFF 就能在这里点亮。控台停止 5 秒后，CONTROL 恢复可用，点它会切换为你手动设置的灯光。如果控台再次开始发送，控台的灯光会回来。

DMX 为 OFF 时，Kanau Lite 不监听控台，始终显示你手动设置的灯光。在 SETUP 中，Art-Net / sACN、Universe 和 Address 会变灰，无法更改。它们的值会保留，把 DMX 重新设为 ON 后照常工作。ON 和 OFF 的选择会被保存。

地址画面

点 START 之后，DMX 为 ON 且还没有任何数据到达时，黑色屏幕用大字显示三行。这就是地址画面。即使很多台并排放着，也能从远处读出每个编号。

  • 琥珀色的 universe 和地址，例如 U1 · 001。
  • 模式，例如 2: SCREEN RGB 9ch。
  • 网络，即这台设备的 IP 地址和它接收的协议，例如 Wi-Fi 192.168.1.24 · Art-Net。没有网络时显示 No network。

它们下方有一行小字，说明如何打开面板。点地址画面没有任何反应。DMX 为 OFF 时不显示地址画面，而是点亮你手动设置的灯光。

CONTROL

CONTROL 用来设置手动点亮时的亮度和颜色。它分为三部分：LIGHT、MACRO 和 MEDIA。你的设置会被保存，下次打开应用时仍然在。滑块不会跳到你触摸的位置，而是随手指移动的距离而移动。

LIGHT 有：

  • Intensity：亮度。
  • WHITE 和 COLOR：选择 WHITE 时，用 Color Temperature、2700、3000、3200、4300、5600 和 6500 按钮以及 Green / Magenta 来设置白光。Green / Magenta 左边是 magenta，右边是 green，在中间附近为 0。选择 COLOR 时，用 Hue 和 Saturation 设置颜色。
  • Back Light：背面灯的亮度。没有背面灯的设备不显示它。

显示图案时，ORIGINAL 取代 WHITE。ORIGINAL 是图案自身的颜色。显示图案、图片或视频时，LIGHT 顶部会出现它的名称和 STOP。STOP 会停止图案和图片，只留下在 LIGHT 中设置的颜色。

MACRO 有：

  • Pattern：从列表中选择图案。包括 SOLID 和19 种流动的图案，与下面 FX & MEDIA 中的 Content 相同。
  • Color Macro：从列表中选择颜色。Original 1 到 6 是图案自带的颜色组合，SOLID 时不在列表中。FROM LIGHT 是在 LIGHT 中设置的颜色，后面是 15 种颜色。在 LIGHT 中更改颜色会取消 Color Macro 的颜色。
  • Speed、Amount 和 Size：图案的速度和样子。图案为 SOLID 时会变灰。

在 MEDIA 中，Media 从保管库里选择图片或视频（见 Media）。列表中有 Off，以及只有存有内容的编号。Play、Pause 和 Restart 控制播放，每点一次 Restart 就从头播放。显示图片或视频时，LIGHT 中的颜色和整个 MACRO 会变灰，只有 Intensity 和 Back Light 起作用。

每次打开 SETUP 时，Channels 都是收起的，只显示通道数，例如 9ch。点标题可以展开当前模式的通道列表，包括地址、名称和数值的含义。关于在 Kanau 和其他控台上登记的两行，收起时也会显示。这台设备没有的功能（背面灯或振动）所在的行会变灰，并以 Not on this device 开头。这一行仍然占用它的地址，所以在控台上也要把它算进去。

SETUP 的末尾有 Kanau Lite 的版本、Made by Kanau Labs、kanaulabs.app 的链接、Privacy Policy、Contact Support、Art-Net 的署名和版权声明。设置会被保存，下次打开应用时仍然在。

灯亮着的时候

屏幕显示它收到的内容。Kanau Lite 打开期间，屏幕保持最大亮度，不会自动锁定。如果控台的 DMX 停止，灯光会保持原样。

当两台控台向同一个 universe 发送 Art-Net 时，Kanau Lite 只监听先到的那一台。如果那台控台停止 5 秒，就改为监听另一台。

Kanau Lite 只在应用打开时接收 DMX。回到 Home 或锁定设备后，它会停止接收，停止背面灯和振动，并把屏幕亮度恢复原样。再次打开，上一次的灯光会回来，并重新开始接收。

屏幕以黑色为底：先是 Media 选的图片或视频，再在上面叠上 Content 选的图案。Mix 设置两者的比例：0 时只看到图片或视频，255 时只看到图案。当 Media 为 0，或该编号里没有内容时，只显示图案。Reserved 1 和 Reserved 2 是什么也不做的通道。

Content 的第一个值 SOLID 用颜色填满屏幕。保持默认值时，FX & MEDIA 给出与 SCREEN RGB 相同的灯光。其余19 个是流动的图案：Speed 设置它们移动的快慢，Amount 和 Size 改变它们的样子。Content 100–255 未使用，作用与 SOLID 相同。

每个图案都有自己的颜色，所以即使不设置颜色，它也以可用的样子运行。Crossfade 为 0 时显示图案自己的颜色，为 255 时显示 Red、Green 和 Blue 的颜色。

Color Macro 以 5 为一档。5–34 的 Original 1 到 6 是图案自带的颜色组合。从 50 起每隔 5 依次是这 15 种颜色：3200 K、4300 K、5600 K、Red、Orange、Amber、Yellow、Green、Cyan、Sky Blue、Blue、Deep Blue、Lavender、Magenta、Pink。0–4、35–49 和 125–255 的作用与 Off 相同。在 CONTROL 中，POLICE 的组合用颜色命名，TRAFFIC LIGHT 和 CROSSWALK 用国家命名（Japan、USA、UK、Germany、France、China），BEACON 无论选哪个都是 Aviation Red。SETUP 的 Channels 中按编号显示。

图片和视频保持它们自己的颜色。Color Temp 让它们偏暖或偏冷，Screen Dimmer 让它们变暗。视频无声播放，结束后从头循环。Playback 用来播放或暂停视频。Restart 在数值进入 171–255 的那一刻，把视频送回开头一次。

COOKIE 和 ULTIMATE

SCREEN COOKIE 把屏幕分成不规则的斑驳区域。每个区域取 8 个格之一的颜色，所以一个格的颜色会出现在屏幕的多处。无论各格是什么颜色，有些区域始终保持黑色，所以即使 8 个格全部点亮，光之间也有阴影。想要更多阴影，请在控台上把其中几个格设为黑色。

16: SCREEN COOKIE RGB 62ch 以 Screen Dimmer 开头，接着是 Shape、Soft 和 Drift。然后是 8 个格，每个格都有 Dimmer、CCT、G/M、Crossfade、Red、Green 和 Blue，与 CELLS 模式相同。最后是 Back Light 和 Vibration。17: SCREEN COOKIE HUE SAT 54ch 的每个格用 Hue 和 Saturation 代替 Red、Green 和 Blue。

#名称数值

3Soft0 Sharp → 255 Soft · Home 0
4Drift0 Still → 255 Fast · Home 0

Shape 选择图案。数值移动时图案平滑变化，所以在控台上推渐变，就会从一个图案变成下一个。Soft 使区域之间的边缘变模糊：为 0 时边缘清晰。Drift 决定图案流动的快慢：为 0 时静止不动。

只有在 Content 为 SOLID 且 Media 为 0 时才显示这些格。此时 Cells 选择屏幕的分割方式。SCREEN 用第 1 格的颜色填满整个屏幕。在显示图案、图片或视频时（Content 不是 SOLID，或 Media 不是 0），屏幕是一整块，与 FX & MEDIA 相同，图案的颜色和 Crossfade 都取自第 1 格。Media 按数值计：只要不是 0，即使该编号里什么也没有，屏幕也是一整块。Color Macro 只在屏幕是一整块时有效。屏幕被分割时，它不起作用。当 Cells 把屏幕分成少于 8 部分时，其余格的通道不起作用，但仍占用各自的地址。

Media

素材架里存放这台设备上的图片和视频，编号从 1 到 51。从 SETUP 的 Media 打开。每种模式下它都在，所以可以在切换到 FX & MEDIA 或 ULTIMATE 之前先放好。

  • 点一个空的编号，可以从 Photos 或 Files 添加图片或视频。
  • 点一个已在使用的编号，可以替换其中的内容、移到另一个编号，或删除。如果另一个编号已在使用，两者会互换。

在控台上，由 Media 通道选择编号：1–5 是 1，6–10 是 2，依此类推，251–255 是 51。文件留在这台设备上，不会被发送到任何地方。

在控台上登记

在 Kanau 上，用相同的模式把这台设备登记为 Kanau Lite（说明书第 03 章）。Kanau 1.2 中的 Kanau Lite 与 Kanau Lite 1.2 有相同的通道，只是它的 Content 里还没有 TRAFFIC LIGHT 和 CROSSWALK（90–99）。按 Kanau Lite 1.1 建的灯具仍可照常使用：1.2 新增的值在 1.1 中是未使用的。

在其他控台上，建立一个通道顺序与 SETUP 的 Channels 相同的灯具，并登记在相同的地址。每个通道都是 8-bit。

按 Kanau Lite 1.0 登记的灯具，在模式 14、15、18 和 19 中通道数不同，Color Macro 和 Content 的数值也不同。请在 Kanau 或任何其他控台上重新登记。

在 Art-Net 上，应用会用 Kanau Lite · U1 · 001 这样的名字回应节点发现（ArtPoll）。在能列出节点的控台上，请找这个名字，以及它的 universe 和地址。

联系方式

请用任何语言写信到 info@kanaulabs.app，或使用 SETUP 里的 Contact Support。报告问题时，请附上 SETUP 末尾显示的 Kanau Lite 版本、所用的模式，以及你的控台和协议。
