Kanau Lite

截至 Kanau Lite 1.0 (6)

Kanau Lite 是一款免费应用，把 iPhone 或 iPad 变成一盏灯。它接收控台通过 Art-Net 或 sACN 发来的 DMX，驱动屏幕、背面灯和振动的颜色与亮度。在 FX & MEDIA 和 ULTIMATE 模式下，屏幕还能显示流动的图案，以及你自己的图片和视频。不需要创建账号，也没有广告。

所需条件

  • 运行 iOS 17 或更高版本的 iPhone 或 iPad。
  • 一台发送 Art-Net 或 sACN 的控台。Kanau 或其他控台都可以。
  • 与控台在同一个网络上，Wi-Fi 或有线均可。第一次打开应用时，它会请求 Local Network 权限，请允许。

开始使用

  1. 打开 Kanau Lite。图标和名称会短暂显示。点一下可以跳过。
  2. Settings 打开。每次打开 Kanau Lite，它都最先出现。
  3. 先选 Mode，再选 Art-Net 或 sACN，然后设定 Universe 和 Address。
  4. 点底部的 START。
  5. 在控台上向该 universe 和地址发送 DMX。数据一到，屏幕就变成灯。

点 START 之前，即使 DMX 到达，屏幕也不会亮起。

地址画面

点 START 之后，没有 DMX 到达时，黑色屏幕用大字显示三行。这就是地址画面。即使很多台并排放着，也能从远处读出每个编号。

  • 琥珀色的 universe 和地址，例如 U1 · 001。
  • 模式，例如 2: SCREEN RGB 9ch。
  • 网络，即这台设备的 IP 地址和它接收的协议，例如 Wi-Fi 192.168.1.24 · Art-Net。没有网络时显示 No network。

点地址画面即可打开 Settings。灯亮着时，如果 6 秒没有 DMX 到达，就会回到地址画面。背面灯和振动也会停止。

Settings

从上往下依次是：

项目作用
Mode显示当前模式，例如 2: SCREEN RGB 9ch。点它可以从下面的模式中选择（见模式与通道）。开头的数字是模式编号。没有背面灯的设备上，列表里没有 1: BACK LIGHT ONLY，但其他模式的编号不变。
Art-Net / sACN点两者之一。选中的那个会变成琥珀色。
UniverseArt-Net 为 0–32767，sACN 为 1–63999。
Address从 1 起，到该模式的通道仍能放进 512 以内的最大地址为止。
Channels当前模式的通道（见下文）。
PROXIMITY打开后，把这台设备贴近耳朵时屏幕会变暗。背面灯和振动继续工作。默认是关闭的。没有接近传感器的设备（例如 iPad）不显示它。
Media显示 51 个编号中有多少个存放了图片或视频，例如 3 / 51。点它可以打开素材架（见 Media）。
LanguageSystem，或 15 种语言之一。一选好，说明文字就会改变。项目和按钮的名称仍然是英文。选择之前，Kanau Lite 显示英文。
Guide打开一份 8 步的简短指南。它在应用内部，所以没有网络也能看。

Universe 和 Address 可以输入数字，也可以用 − 和 +。下面的琥珀色一行显示屏幕、背面灯和振动所用的地址，例如 Screen 001–007 · Back Light 008 · Vibration 009。

接着是 Channels。每次打开 Settings 时它都是收起的，只显示通道数，例如 9ch。点标题可以展开当前模式的通道列表，包括地址、名称和数值的含义。关于在 Kanau 和其他控台上登记的两行，收起时也会显示。这台设备没有的功能（背面灯或振动）所在的行会变灰，并以 Not on this device 开头。这一行仍然占用它的地址，所以在控台上也要把它算进去。

Settings 的末尾有 Kanau Lite 的版本、Made by Kanau Labs、kanaulabs.app 的链接、Privacy Policy、Contact Support、Art-Net 的署名和版权声明。设置会被保存，下次打开应用时仍然在。

灯亮着的时候

屏幕显示它收到的内容。Kanau Lite 打开期间，屏幕保持最大亮度，不会自动锁定。

灯亮着时要打开 Settings，先把右上角淡淡的开关一直滑到右边，再点出现的 ×。× 会在 3 秒后消失。这样打开的 Settings，用左上角的 × 关闭。

Kanau Lite 只在应用打开时接收 DMX。回到 Home 或锁定设备后，它会停止接收，停止背面灯和振动，并把屏幕亮度恢复原样。再次打开才会再次接收。

HUE SAT 模式用 Hue（0–360°）和 Saturation 代替 Red、Green 和 Blue。在 CELLS 和 STRIPS 模式中，Screen Dimmer 之后，屏幕的每一部分各有 Dimmer、CCT、G/M、Crossfade 和颜色。CELLS 从左上开始编号。8 块在竖着放的屏幕上是 2 列 4 行，在横着放的屏幕上是 4 列 2 行。STRIPS 是沿屏幕长边排列的等宽条。竖放的屏幕是横条，从上到下编号；横放的屏幕是竖条，从左到右编号。正方形屏幕从上到下分割。

Crossfade 设定白色和颜色的混合：0 是白色，255 是颜色。白色由 CCT 和 G/M 决定。Crossfade 在 0 时，调高 Red、Green 或 Blue，屏幕仍然是白色。Screen Dimmer 只让屏幕变暗，不影响背面灯。

屏幕从黑色开始叠加：先是 Media 选中的图片或视频，再在上面叠上 Content 选中的图案。Mix 决定两者各显示多少：0 只显示图片或视频，255 只显示图案。Media 为 0，或者那个编号里什么都没有时，只显示图案。

Content 的第一项 SOLID 用颜色填满屏幕。在 Home 值时，FX & MEDIA 发出的光与 SCREEN RGB 相同。其余七项是会动的图案。Speed 决定它们动得多快，Amount 和 Size 改变各个图案的样子。每个图案都有自己的颜色，所以即使不设定颜色，看起来也是完整的。Crossfade 让图案从 0 时自己的颜色，过渡到 255 时 Red、Green 和 Blue 的颜色。Color Macro 不为 0 时，改用宏颜色。从 16 开始，每 16 个值选下一种颜色：3200 K、4300 K、5600 K、Red、Orange、Amber、Yellow、Green、Cyan、Sky Blue、Blue、Deep Blue、Lavender、Magenta、Pink。

图片和视频保持自己的颜色。Color Temp 让它们偏暖或偏冷，Screen Dimmer 让它们变暗。视频无声播放，播完后从头再来。Playback 播放或暂停视频。Restart 在数值进入 171–255 的那一刻，让视频回到开头一次。

COOKIE 和 ULTIMATE

SCREEN COOKIE 把屏幕分成不规则的斑驳区域。每个区域取 8 个格之一的颜色，所以一个格的颜色会出现在屏幕的多处。无论各格是什么颜色，有些区域始终保持黑色，所以即使 8 个格全部点亮，光之间也有阴影。想要更多阴影，请在控台上把其中几个格设为黑色。

16: SCREEN COOKIE RGB 62ch 以 Screen Dimmer 开头，接着是 Shape、Soft 和 Drift。然后是 8 个格，每个格都有 Dimmer、CCT、G/M、Crossfade、Red、Green 和 Blue，与 CELLS 模式相同。最后是 Back Light 和 Vibration。17: SCREEN COOKIE HUE SAT 54ch 的每个格用 Hue 和 Saturation 代替 Red、Green 和 Blue。

#名称数值
2Shape0–255 Pattern · Home 0
3Soft0 Sharp → 255 Soft · Home 0
4Drift0 Still → 255 Fast · Home 0

Shape 选择图案。数值移动时图案平滑变化，所以在控台上推渐变，就会从一个图案变成下一个。Soft 使区域之间的边缘变模糊：为 0 时边缘清晰。Drift 决定图案流动的快慢：为 0 时静止不动。

只有在 Content 为 SOLID 且 Media 为 0 时才显示这些格。此时 Cells 选择屏幕的分割方式。SCREEN 用第 1 格的颜色填满整个屏幕。在显示图案、图片或视频时（Content 不是 SOLID，或 Media 不是 0），屏幕是一整块，与 FX & MEDIA 相同，图案的颜色和 Crossfade 都取自第 1 格。Media 按数值计：只要不是 0，即使该编号里什么也没有，屏幕也是一整块。Color Macro 只在屏幕是一整块时有效。屏幕被分割时，它不起作用。当 Cells 把屏幕分成少于 8 部分时，其余格的通道不起作用，但仍占用各自的地址。

Media

素材架里存放这台设备上的图片和视频，编号从 1 到 51。从 Settings 的 Media 打开。每种模式下它都在，所以可以在切换到 FX & MEDIA 或 ULTIMATE 之前先放好。

  • 点一个空的编号，可以从 Photos 或 Files 添加图片或视频。
  • 点一个已在使用的编号，可以替换其中的内容、移到另一个编号，或删除。如果另一个编号已在使用，两者会互换。

在控台上，由 Media 通道选择编号：1–5 是 1，6–10 是 2，依此类推，251–255 是 51。文件留在这台设备上，不会被发送到任何地方。

在控台上登记

在 Kanau 上，用相同的模式把这台设备登记为 Kanau Lite（说明书第 03 章）。在 Kanau 1.0 (372) 及之后的版本中，Kanau Lite 有全部 19 种模式。

在其他控台上，建立一个通道顺序与 Settings 的 Channels 相同的灯具，并登记在相同的地址。每个通道都是 8-bit。

在 Art-Net 上，应用会用 Kanau Lite · U1 · 001 这样的名字回应节点发现（ArtPoll）。在能列出节点的控台上，请找这个名字，以及它的 universe 和地址。

与 Kanau 中的 LITE MODE 有何不同

Kanau Lite 的接收方式与 Kanau 中的 LITE MODE 相同（说明书第 02 章）。自 Kanau 1.0 (375) 起，有三点不同。

  • DMX 到达之前，LITE MODE 显示 WAITING。Kanau Lite 显示地址画面。
  • DMX 中断时，LITE MODE 保持最后的颜色。Kanau Lite 在 6 秒后回到地址画面。
  • 右上角开关里的 × 在 Kanau 中是退出 LITE MODE。在 Kanau Lite 中是打开 Settings。

联系方式

请用任何语言写信到 info@kanaulabs.app，或使用 Settings 里的 Contact Support。报告问题时，请附上 Settings 末尾显示的 Kanau Lite 版本、所用的模式，以及你的控台和协议。
