Kanau Lite

ณ Kanau Lite 1.1 (18)

Kanau Lite เป็นแอปฟรีที่เปลี่ยน iPhone หรือ iPad ให้เป็นดวงไฟหนึ่งดวง รับ DMX ที่ส่งมาจากคอนโซลผ่าน Art-Net หรือ sACN แล้วขับสีและความสว่างของหน้าจอ ไฟหลัง และการสั่น ไม่ต้องสร้างบัญชี และไม่มีโฆษณา

หากไม่มีคอนโซล ก็ตั้งความสว่างและสีใน CONTROL แล้วจุดไฟด้วยมือได้ ในโหมด FX & MEDIA และ ULTIMATE หน้าจอยังแสดงลวดลายที่เคลื่อนไหวและภาพกับวิดีโอของคุณเองได้ด้วย

สิ่งที่ต้องมี

  • iPhone หรือ iPad ที่ใช้ iOS 17 ขึ้นไป
  • หากต้องการควบคุมจากคอนโซล ต้องมีคอนโซลที่ส่ง Art-Net หรือ sACN จะเป็น Kanau หรือคอนโซลอื่นก็ได้
  • เครือข่ายเดียวกับคอนโซล ผ่าน Wi-Fi หรือสายก็ได้ ตอนเปิดแอปครั้งแรก แอปจะขอสิทธิ์ Local Network ให้อนุญาต

เริ่มต้นใช้งาน

  1. เปิด Kanau Lite ไอคอนและชื่อจะแสดงอยู่ครู่หนึ่ง แตะเพื่อข้ามได้
  2. แผงจะเปิดขึ้นจากด้านล่างของหน้าจอ ที่ SETUP Kanau Lite เริ่มต้นแบบนี้ทุกครั้งที่เปิด
  3. เลือก Mode ก่อน จากนั้นเลือก Art-Net หรือ sACN แล้วตั้ง Universe และ Address
  4. แตะ START ที่ด้านล่าง แผงจะปิด
  5. จากคอนโซล ให้ส่ง DMX ไปยังยูนิเวิร์สและแอดเดรสนั้น เมื่อ DMX มาถึง หน้าจอจะกลายเป็นดวงไฟ

จนกว่าจะแตะ START หน้าจอจะไม่สว่าง แม้ DMX จะเข้ามาก็ตาม หากต้องการจุดไฟโดยไม่มีคอนโซล ให้แตะ CONTROL ที่ด้านบนของแผงแทนขั้นตอนที่ 3 ตั้งความสว่างและสี แล้วแตะ START (ดู CONTROL)

แผง

แผงเปิดขึ้นจากด้านล่างของหน้าจอ และประมาณหนึ่งในสามส่วนบนของหน้าจอยังแสดงไฟอยู่ จากด้านบน แผงมีดังนี้

  • × ที่มุมซ้ายบน และปุ่มสองปุ่ม คือ CONTROL และ SETUP
  • แถว DMX (ดู การเปิดและปิด DMX)
  • ขณะที่ CONTROL เปิดอยู่ จะมีปุ่ม LIGHT, MACRO และ MEDIA
  • เนื้อหาของหน้าจอที่เลือก และ START ที่ด้านล่าง START อยู่ตำแหน่งเดียวกันในทุกหน้าจอ

หากต้องการปิดแผง ให้แตะ START แตะ × ที่มุมซ้ายบน หรือจับเส้นที่ขอบบนของแผงแล้วปัดลง แต่ละวิธีให้ผลเหมือนกับ START

หากต้องการเปิดแผงขณะที่ไฟติดอยู่ ให้เลื่อนสวิตช์จางๆ ที่มุมขวาบนไปทางขวาสุด แล้วแตะ EDIT EDIT จะหายไปหลังจาก 3 วินาที การแตะที่ไฟหรือหน้าจอแอดเดรสจะไม่เปิดแผง

การเปิดและปิด DMX

ใต้ปุ่มสองปุ่มของแผงพอดีคือแถว DMX จากซ้าย: ON และ OFF ของ DMX แอดเดรส (เช่น U1 · 001) และสัญญาณ สัญญาณจะแสดง Receiving ขณะที่ DMX เข้ามา และ No Signal ขณะที่ไม่มีเข้ามา

ขณะที่ DMX เป็น ON ไฟจากคอนโซลมาก่อนเสมอเมื่อคอนโซลกำลังส่งอยู่ ขณะที่ส่งอยู่ CONTROL จะจางและแตะไม่ได้ และมีบรรทัดด้านล่างบอกเหตุผล พร้อมบอกว่าการตั้ง DMX เป็น OFF จะทำให้จุดไฟที่นี่ได้ เมื่อคอนโซลหยุดนาน 5 วินาที CONTROL จะใช้งานได้อีกครั้ง และการแตะจะเปลี่ยนไปใช้ไฟที่คุณตั้งด้วยมือ หากคอนโซลเริ่มส่งอีก ไฟจากคอนโซลจะกลับมา

เมื่อ DMX เป็น OFF Kanau Lite จะไม่ฟังคอนโซลและแสดงไฟที่คุณตั้งด้วยมือเสมอ ใน SETUP Art-Net / sACN, Universe และ Address จะจางและเปลี่ยนไม่ได้ ค่าเหล่านี้ยังคงอยู่ และใช้งานได้เหมือนเดิมเมื่อคุณตั้ง DMX กลับเป็น ON การเลือก ON หรือ OFF จะถูกบันทึกไว้

หน้าจอแอดเดรส

หลัง START ขณะที่ DMX เป็น ON และยังไม่มีอะไรเข้ามา หน้าจอสีดำจะแสดงสามบรรทัดด้วยตัวอักษรขนาดใหญ่ นี่คือหน้าจอแอดเดรส เมื่อวางหลายเครื่องเรียงกัน ก็อ่านตัวเลขของแต่ละเครื่องได้จากระยะไกล

  • ยูนิเวิร์สและแอดเดรส แสดงเป็นสีอำพัน เช่น U1 · 001
  • โหมด เช่น 2: SCREEN RGB 9ch
  • เครือข่าย คือที่อยู่ IP ของเครื่องนี้และโปรโตคอลที่รับฟัง เช่น Wi-Fi 192.168.1.24 · Art-Net ถ้าไม่มีเครือข่ายจะแสดง No network

ด้านล่างมีบรรทัดเล็กๆ บอกวิธีเปิดแผง การแตะหน้าจอแอดเดรสไม่ทำอะไร ขณะที่ DMX เป็น OFF จะไม่แสดงหน้าจอแอดเดรส แต่ไฟที่คุณตั้งด้วยมือจะติดแทน

CONTROL

CONTROL คือที่ที่คุณตั้งความสว่างและสีเพื่อจุดไฟด้วยมือ มีสามส่วน คือ LIGHT, MACRO และ MEDIA ค่าที่คุณตั้งจะถูกบันทึกไว้และยังอยู่เมื่อเปิดแอปครั้งต่อไป สไลเดอร์จะไม่กระโดดไปยังจุดที่คุณแตะ แต่เคลื่อนไปตามระยะที่นิ้วของคุณเคลื่อน

LIGHT มี:

  • Intensity: ความสว่าง
  • WHITE และ COLOR: เมื่อเลือก WHITE ให้ตั้งสีขาวด้วย Color Temperature ปุ่ม 2700, 3000, 3200, 4300, 5600 และ 6500 และ Green / Magenta โดย Green / Magenta มี magenta อยู่ทางซ้ายและ green อยู่ทางขวา และเป็น 0 ใกล้ตรงกลาง เมื่อเลือก COLOR ให้ตั้งสีด้วย Hue และ Saturation
  • Back Light: ความสว่างของไฟหลัง เครื่องที่ไม่มีไฟหลังจะไม่แสดงรายการนี้

ขณะที่แสดงลวดลาย ORIGINAL จะมาแทน WHITE ORIGINAL คือสีของลวดลายเอง ขณะที่แสดงลวดลาย ภาพ หรือวิดีโอ ชื่อของมันและ STOP จะปรากฏที่ด้านบนของ LIGHT STOP จะหยุดลวดลายและภาพ เหลือไว้เพียงสีที่ตั้งไว้ใน LIGHT

MACRO มี:

  • Pattern: เลือกลวดลายจากรายการ มี SOLID และลวดลายที่เคลื่อนไหวเก้าแบบ เหมือนกับ Content ใน FX & MEDIA ด้านล่าง
  • Color Macro: เลือกสีจากรายการ Original 1 ถึง 3 คือชุดสีที่เป็นของลวดลายนั้น และไม่อยู่ในรายการสำหรับ SOLID FROM LIGHT คือสีที่ตั้งไว้ใน LIGHT ตามด้วยสี 15 สี การเปลี่ยนสีใน LIGHT จะยกสีของ Color Macro ออก
  • Speed, Amount และ Size: ความเร็วและหน้าตาของลวดลาย จะจางลงขณะที่ลวดลายเป็น SOLID

ใน MEDIA ตัว Media จะเลือกภาพหรือวิดีโอจากชั้นเก็บ (ดู Media) รายการมี Off และเฉพาะหมายเลขที่มีเนื้อหาอยู่ Play, Pause และ Restart ควบคุมการเล่น และการแตะ Restart แต่ละครั้งจะเล่นจากต้นใหม่ ขณะที่แสดงภาพหรือวิดีโอ สีใน LIGHT และ MACRO ทั้งหมดจะจางลง และใช้ได้เฉพาะ Intensity กับ Back Light

พิมพ์ตัวเลขสำหรับ Universe และ Address หรือใช้ − และ + บรรทัดสีอำพันด้านล่างแสดงแอดเดรสที่หน้าจอ ไฟหลัง และการสั่นใช้ เช่น Screen 001–007 · Back Light 008 · Vibration 009

ทุกครั้งที่เปิด SETUP ส่วน Channels จะพับอยู่และแสดงเพียงจำนวนแชนเนล เช่น 9ch แตะหัวข้อเพื่อเปิดรายการแชนเนลของโหมดปัจจุบัน พร้อมแอดเดรส ชื่อ และความหมายของค่า ส่วนสองบรรทัดเรื่องการแพตช์บน Kanau และบนคอนโซลอื่นจะแสดงอยู่แม้พับอยู่ แถวของฟีเจอร์ที่เครื่องนี้ไม่มี (ไฟหลังหรือการสั่น) จะจางลงและขึ้นต้นด้วย Not on this device แถวนั้นยังใช้แอดเดรสของมันอยู่ ดังนั้นให้นับรวมบนคอนโซลด้วย

ท้ายสุดของ SETUP มีเวอร์ชันของ Kanau Lite, Made by Kanau Labs, ลิงก์ไปยัง kanaulabs.app, Privacy Policy, Contact Support, เครดิต Art-Net และข้อความลิขสิทธิ์ การตั้งค่าจะถูกบันทึกไว้และยังอยู่เมื่อเปิดแอปครั้งต่อไป

ขณะที่ไฟติดอยู่

หน้าจอแสดงสิ่งที่ได้รับ ขณะที่ Kanau Lite เปิดอยู่ หน้าจอจะสว่างเต็มที่และไม่ล็อกอัตโนมัติ หาก DMX จากคอนโซลหยุด ไฟจะคงอยู่ตามเดิม

เมื่อคอนโซลสองเครื่องส่ง Art-Net ไปยังยูนิเวิร์สเดียวกัน Kanau Lite จะฟังเฉพาะเครื่องที่มาถึงก่อน หากคอนโซลเครื่องนั้นหยุดนาน 5 วินาที ก็จะฟังอีกเครื่อง

Kanau Lite รับ DMX เฉพาะขณะที่แอปเปิดอยู่ หากกลับไปที่ Home หรือล็อกเครื่อง แอปจะหยุดรับ หยุดไฟหลังและการสั่น และตั้งความสว่างหน้าจอกลับเป็นค่าเดิม เปิดแอปอีกครั้ง ไฟล่าสุดจะกลับมาและแอปจะรับต่อ
