Kanau Lite

截至 Kanau Lite 1.0 (4)

Kanau Lite 是一款免費 App，把 iPhone 或 iPad 變成一盞燈。它接收控台透過 Art-Net 或 sACN 送來的 DMX，驅動螢幕、背面燈和震動的顏色與亮度。在 FX & MEDIA 模式下，螢幕還能顯示流動的圖案，以及你自己的圖片和影片。不需要建立帳號，也沒有廣告。

所需條件

  • 執行 iOS 17 或更新版本的 iPhone 或 iPad。
  • 一台傳送 Art-Net 或 sACN 的控台。Kanau 或其他控台都可以。
  • 與控台在同一個網路上，Wi-Fi 或有線皆可。第一次打開 App 時，它會請求 Local Network 權限，請允許。

開始使用

  1. 打開 Kanau Lite。圖示和名稱會短暫顯示。點一下可以略過。
  2. Settings 打開。每次打開 Kanau Lite，它都最先出現。
  3. 選 Art-Net 或 sACN。然後設定 Mode、Universe 和 Address。
  4. 點底部的 START。
  5. 在控台上向該 universe 和位址傳送 DMX。資料一到，螢幕就變成燈。

點 START 之前，即使 DMX 到達，螢幕也不會亮起。

位址畫面

點 START 之後，沒有 DMX 到達時，黑色螢幕用大字顯示三行。這就是位址畫面。即使很多台並排放著，也能從遠處讀出每個編號。

  • 琥珀色的 universe 和位址，例如 U1 · 001。
  • 模式，例如 SCREEN RGB 10ch。
  • 網路，即這台裝置的 IP 位址和它接收的協定，例如 Wi-Fi 192.168.1.24 · Art-Net。沒有網路時顯示 No network。

點位址畫面即可打開 Settings。燈亮著時，如果 6 秒沒有 DMX 到達，就會回到位址畫面。背面燈和震動也會停止。

Settings

從上往下依序是：

項目作用
LanguageSystem，或 15 種語言之一。一選好，說明文字就會改變。項目和按鈕的名稱仍然是英文。選擇之前，Kanau Lite 顯示英文。
Guide打開一份 8 步的簡短指南。它在 App 內部，所以沒有網路也能看。
Art-Net / sACN點兩者之一。選中的那個會變成琥珀色。
Mode顯示目前的模式，例如 SCREEN RGB 10ch。點它可以從下面的模式中選擇（見模式與通道）。裝置沒有背面燈時，清單裡不列 BACK LIGHT ONLY。
UniverseArt-Net 為 0–32767，sACN 為 1–63999。
Address從 1 起，到該模式的通道仍能放進 512 以內的最大位址為止。
Media顯示 51 個編號中有多少個存放了圖片或影片，例如 3 / 51。點它可以打開素材架（見 Media）。

Universe 和 Address 可以輸入數字，也可以用 − 和 +。下面的琥珀色一行顯示螢幕、背面燈和震動所用的位址，例如 Screen 001–008 · Back Light 009 · Vibration 010。

接下來是 Channels。每次打開 Settings 時它都是收起的，只顯示通道數，例如 10ch。點標題可以展開目前模式的通道清單，包括位址、名稱和數值的意思。關於在 Kanau 和其他控台上 patch 的兩行，收起時也會顯示。這台裝置沒有的功能（背面燈或震動）所在的列會變灰，並以 Not on this device 開頭。這一列仍然占用它的位址，所以在控台上也要把它算進去。

Settings 的末尾有 Kanau Lite 的版本、Made by Kanau Labs、kanaulabs.app 的連結、Privacy Policy、Contact Support、Art-Net 的署名和版權聲明。設定會被儲存，下次打開 App 時仍然在。

燈亮著的時候

螢幕顯示它收到的內容。Kanau Lite 打開期間，螢幕保持最亮，不會自動鎖定。

燈亮著時要打開 Settings，先把右上角淡淡的開關一直滑到右邊，再點出現的 ×。× 會在 3 秒後消失。這樣打開的 Settings，用左上角的 × 關閉。

Kanau Lite 只在 App 打開時接收 DMX。回到 Home 或鎖定裝置後，它會停止接收，停止背面燈和震動，並把螢幕亮度恢復原樣。再次打開才會再次接收。

HUE SAT 模式用 Hue（0–360°）和 Saturation 代替 Red、Green 和 Blue。在 CELLS 和 STRIPS 模式中，Screen Dimmer 之後，螢幕的每一部分各有 Dimmer、CCT、G/M、Crossfade 和顏色。CELLS 從左上開始編號。8 塊在直放的螢幕上是 2 欄 4 列，在橫放的螢幕上是 4 欄 2 列。STRIPS 是等寬的直條，無論直放還是橫放，都從左到右編號。

Crossfade 設定白色和顏色的混合：0 是白色，255 是顏色。白色由 CCT 和 G/M 決定。Crossfade 在 0 時，調高 Red、Green 或 Blue，螢幕仍然是白色。Screen Dimmer 只讓螢幕變暗，不影響背面燈。把 Function 設為 128 或更高就選到 Proximity，它使用裝置的近接感應器。

螢幕從黑色開始疊加：先是 Media 選中的圖片或影片，再在上面疊上 Content 選中的圖案。Mix 決定兩者各顯示多少：0 只顯示圖片或影片，255 只顯示圖案。Media 為 0，或者那個編號裡什麼都沒有時，只顯示圖案。

Content 的第一項 SOLID 用顏色填滿螢幕。在 Home 值時，FX & MEDIA 發出的光與 SCREEN RGB 相同。其餘七項是會動的圖案。Speed 決定它們動得多快，Amount 和 Size 改變各個圖案的樣子。圖案的顏色取自螢幕的顏色。Color Macro 不為 0 時，改用巨集顏色。從 16 開始，每 16 個值選下一種顏色：3200 K、4300 K、5600 K、Red、Orange、Amber、Yellow、Green、Cyan、Sky Blue、Blue、Deep Blue、Lavender、Magenta、Pink。

圖片和影片保持自己的顏色。Color Temp 讓它們偏暖或偏冷，Screen Dimmer 讓它們變暗。影片無聲播放，播完後從頭再來。Playback 播放或暫停影片。Restart 在數值進入 171–255 的那一刻，讓影片回到開頭一次。

Media

素材架裡存放這台裝置上的圖片和影片，編號從 1 到 51。從 Settings 的 Media 打開。每種模式下它都在，所以可以在切換到 FX & MEDIA 之前先放好。

  • 點一個空的編號，可以從 Photos 或 Files 加入圖片或影片。
  • 點一個已在使用的編號，可以取代其中的內容、移到另一個編號，或刪除。如果另一個編號已在使用，兩者會互換。

在控台上，由 Media 通道選擇編號：1–5 是 1，6–10 是 2，依此類推，251–255 是 51。檔案留在這台裝置上，不會被傳送到任何地方。

在控台上 patch

在 Kanau 上，用相同的模式把這台裝置 patch 成 Kanau Screen（說明書第 03 章）。自 Kanau 0.2 (368) 起，Kanau 中的 Kanau Screen 有前 9 種模式，從 BACK LIGHT ONLY 到 SCREEN 8 CELLS HUE SAT。STRIPS 和 FX & MEDIA 模式請像在其他控台上那樣自己建立燈具。

在其他控台上，建立一個通道順序與 Settings 的 Channels 相同的燈具，並 patch 在相同的位址。每個通道都是 8-bit。

在 Art-Net 上，App 會用 Kanau Screen · U1 · 001 這樣的名字回應節點探索（ArtPoll）。在能列出節點的控台上，請找這個名字，以及它的 universe 和位址。

與 Kanau 中的 LITE MODE 有何不同

Kanau Lite 的接收方式與 Kanau 中的 LITE MODE 相同（說明書第 02 章）。自 Kanau 0.2 (368) 起，有四點不同。

  • DMX 到達之前，LITE MODE 顯示 WAITING。Kanau Lite 顯示位址畫面。
  • DMX 中斷時，LITE MODE 保持最後的顏色。Kanau Lite 在 6 秒後回到位址畫面。
  • 右上角開關裡的 × 在 Kanau 中是離開 LITE MODE。在 Kanau Lite 中是打開 Settings。
  • LITE MODE 有前 9 種模式。Kanau Lite 還有 STRIPS 和 FX & MEDIA 模式，以及 Media 素材架。

聯絡方式
