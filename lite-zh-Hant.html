Kanau Lite

截至 Kanau Lite 1.0 (3)

Kanau Lite 是一款免費 App，把 iPhone 或 iPad 變成一盞燈。它接收控台透過 Art-Net 或 sACN 送來的 DMX，驅動螢幕、背面燈和震動的顏色與亮度。它就是 Kanau 的 LITE MODE，做成了獨立的 App。不需要建立帳號，也沒有廣告。

所需條件

  • 執行 iOS 17 或更新版本的 iPhone 或 iPad。
  • 一台傳送 Art-Net 或 sACN 的控台。Kanau 或其他控台都可以。
  • 與控台在同一個網路上，Wi-Fi 或有線皆可。第一次打開 App 時，它會請求 Local Network 權限，請允許。

開始使用

  1. 打開 Kanau Lite。圖示和名稱會短暫顯示。點一下可以略過。DMX 一到，它們也會馬上消失。
  2. 黑色螢幕用大字顯示這台裝置接收的編號。這就是位址畫面。點它的任何位置即可打開 Settings。
  3. 選 Art-Net 或 sACN。然後設定 Mode、Universe 和 Address。
  4. 點左上角的 × 關閉 Settings。
  5. 在控台上向該 universe 和位址傳送 DMX。資料一到，螢幕就變成燈。

位址畫面

沒有 DMX 到達時，黑色螢幕顯示三行。即使很多台並排放著，也能從遠處讀出每個編號。

  • 琥珀色的 universe 和位址，例如 U1 · 001。
  • 模式，例如 SCREEN RGB 10ch。
  • 網路，即這台裝置的 IP 位址和它接收的協定，例如 Wi-Fi 192.168.1.24 · Art-Net。沒有網路時顯示 No network。

燈亮著時，如果 6 秒沒有 DMX 到達，就會回到位址畫面。背面燈和震動也會停止。

Settings

項目設定內容
Art-Net / sACN點兩者之一。選中的那個會變成琥珀色。
Mode顯示目前的模式，例如 SCREEN RGB 10ch。點它可以從下面的模式中選擇（見模式與通道）。裝置沒有背面燈時，清單裡不列 BACK LIGHT ONLY。
UniverseArt-Net 為 0–32767，sACN 為 1–63999。
Address從 1 起，到該模式的通道仍能放進 512 以內的最大位址為止。

Universe 和 Address 可以輸入數字，也可以用 − 和 +。下面的琥珀色一行顯示螢幕、背面燈和震動所用的位址，例如 Screen 001–008 · Back Light 009 · Vibration 010。

再下面是 Channels。每次打開 Settings 時它都是收起的，只顯示通道數，例如 10ch。點標題可以展開目前模式的通道清單，包括位址、名稱和數值的意思。關於在 Kanau 和其他控台上 patch 的兩行，收起時也會顯示。這台裝置沒有的功能（背面燈或震動）所在的列會變灰，並以 Not on this device 開頭。這一列仍然占用它的位址，所以在控台上也要把它算進去。

Settings 的末尾有 Kanau Lite 的版本、Made by Kanau Labs 和 kanaulabs.app 的連結。設定會被儲存，下次打開 App 時仍然在。

燈亮著的時候

螢幕顯示它收到的顏色。Kanau Lite 打開期間，螢幕保持最亮，不會自動鎖定。

燈亮著時要打開 Settings，先把右上角淡淡的開關一直滑到右邊，再點出現的 ×。× 會在 3 秒後消失。

Kanau Lite 只在 App 打開時接收 DMX。回到 Home 或鎖定裝置後，它會停止接收，停止背面燈和震動，並把螢幕亮度恢復原樣。再次打開才會再次接收。

模式與通道

共有 9 種模式。預設是 SCREEN RGB 10ch。

模式螢幕
BACK LIGHT ONLY 1ch只用背面燈。螢幕保持暗著。
SCREEN RGB 10ch
SCREEN HUE SAT 9ch		整個螢幕是一種顏色。
SCREEN 2 CELLS RGB 18ch
SCREEN 2 CELLS HUE SAT 16ch		螢幕分成 2 塊。
SCREEN 4 CELLS RGB 32ch
SCREEN 4 CELLS HUE SAT 28ch		螢幕分成 4 塊。
SCREEN 8 CELLS RGB 60ch
SCREEN 8 CELLS HUE SAT 52ch		螢幕分成 8 塊。

除了 BACK LIGHT ONLY，每種模式都以 Screen Dimmer 開頭，以 Function、Back Light 和 Vibration 結尾。SCREEN RGB 10ch 依下面的順序有這些通道。數值照它們在 Settings 的 Channels 中的樣子寫出。

#名稱數值
1Screen Dimmer0–100%
2CCT1,750–9,910 K · Home 117 = 5,494 K
3G/M0–4 No effect · 5 Magenta → 255 Green · Home 128
4Crossfade0 White → 255 Color · Home 0
5Red0–100%
6Green0–100%
7Blue0–100%
8Function0–127 Off · 128–255 Proximity · Home 0
9Back Light0–100%
10Vibration0–100%

HUE SAT 模式用 Hue（0–360°）和 Saturation 代替 Red、Green 和 Blue。在 CELLS 模式中，Screen Dimmer 之後，螢幕的每一塊各有 Dimmer、CCT、G/M、Crossfade 和顏色。各塊從左上開始編號。8 塊在直放的螢幕上是 2 欄 4 列，在橫放的螢幕上是 4 欄 2 列。

Crossfade 設定白色和顏色的混合：0 是白色，255 是顏色。白色由 CCT 和 G/M 決定。Crossfade 在 0 時，調高 Red、Green 或 Blue，螢幕仍然是白色。Screen Dimmer 只讓螢幕變暗，不影響背面燈。把 Function 設為 128 或更高就選到 Proximity，它使用裝置的近接感應器。

在控台上 patch

在 Kanau 上，用相同的模式把這台裝置 patch 成 Kanau Screen（說明書第 03 章）。

在其他控台上，建立一個通道順序與 Settings 的 Channels 相同的燈具，並 patch 在相同的位址。每個通道都是 8-bit。

在 Art-Net 上，App 會用 Kanau Screen · U1 · 001 這樣的名字回應節點探索（ArtPoll）。在能列出節點的控台上，請找這個名字，以及它的 universe 和位址。

與 Kanau 中的 LITE MODE 有何不同

Kanau Lite 的接收方式和模式與 Kanau 中的 LITE MODE 相同（說明書第 02 章）。有三點不同。

  • DMX 到達之前，LITE MODE 顯示 WAITING。Kanau Lite 顯示位址畫面。
  • DMX 中斷時，LITE MODE 保持最後的顏色。Kanau Lite 在 6 秒後回到位址畫面。
  • 右上角開關裡的 × 在 Kanau 中是離開 LITE MODE。在 Kanau Lite 中是打開 Settings。

聯絡方式
